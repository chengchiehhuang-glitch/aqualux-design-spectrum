# M39 · 3D 傾斜卡片 / Tilt Cards

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with an immersive, interactive 3D tilt card aesthetic, responding to cursor movements to simulate depth and perspective.

### 色票
```

--shadow-light: rgba(0,0,0,0.05) 輕陰影
--shadow-deep:  rgba(0,0,0,0.15) 深陰影
```

### 字型系統
- **Display（標題、Z01 巨型字）**：Montserrat 700/800 — 現代、清晰，具設計感
- **Body（內文、卡片文字）**：Lato 400/600
- **Mono（meta、時間軸）**：Source Code Pro 300/500
- **Japanese accent**：Noto Sans JP — 用於次標、設計師名

### 動態效果
1. **Tilt Cards**：卡片元素基於滑鼠位置 `transform: perspective(1000px) rotateX(var(--rotateX)) rotateY(var(--rotateY))` 產生 3D 傾斜效果。
2. **Subtle Depth**：卡片 `box-shadow` 隨傾斜角度微幅變化，強化立體感。
3. **Smooth Transition**：所有 `transform` 和 `box-shadow` 變化使用 `transition: transform 0.1s ease-out, box-shadow 0.1s ease-out`，確保流暢體驗。
4. **Hover Lift**：滑鼠懸停時，卡片 `transform: translateY(-5px)` 輕微上浮。
5. **Parallax Background**：背景元素（如 Hero 區的幾何圖形）對滑鼠移動做出輕微視差滾動，增加層次。

### 構圖原則
- 淺色背景為主，卡片留白充足。
- 卡片邊緣輕微陰影，營造浮空感。
- 資訊排版簡潔，層次分明，避免過度裝飾。
- 運用 grid 或 flexbox 進行卡片網格佈局，保持視覺一致性。
- 避免複雜背景圖案，以襯托卡片的 3D 效果。

## 互動行為

- 所有卡片元素 `transform: perspective(1000px)` 啟用 3D 空間。
- `mousemove` 事件監聽，計算滑鼠相對於卡片中心的偏移，動態更新 CSS 自訂屬性 `--rotateX` 和 `--rotateY`。
- `mouseleave` 事件重置卡片 `transform` 為初始狀態。
- 卡片 `box-shadow` 隨 `--rotateX` 和 `--rotateY` 變動，模擬光影變化。
- `PURCHASE` 按鈕現為 `disabled aria-label="Demo only — not for sale"`。
- 背景的視差元素（若有）對滑鼠移動做出輕微的 `transform: translate()`。

---

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有 3D 傾斜、視差滾動及複雜動態，只保留靜態卡片與基本 hover 效果。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- 儘量使用 CSS `transform` 屬性進行動態，利用 GPU 加速，減少主執行緒負擔。

寫其他 39 個 Skills 時，可保留這個 M39 的結構骨架（8 區段）但**換掉所有視覺語彙**：
