```

--text-light:  #e0e0e0   淺色文字
--text-dark:   #9e9e9e   深色文字
```

### 字型系統
- **Display（標題、巨型字）**：Montserrat 600/700 — 現代、簡潔、與幾何球體協調
- **Body（內文）**：Open Sans 300/400 — 易讀、流暢
- **Mono（meta、時間軸）**：Fira Code 300/500 — 程式碼風格，用於技術或排程資訊

### 動態效果
1. **Floating Orbs**：多個 `::before` / `::after` 偽元素或獨立 `div`，應用 CSS `animation` 結合 `transform: translate()` 和 `sine-wave` 函數（或 `cubic-bezier` 模擬），以不同 `animation-delay` 和 `duration` 實現錯落的浮動效果。球體大小、透明度、顏色漸變隨機變化。
2. **Subtle Pulsing Glow**：Orbs 核心或邊緣 `box-shadow` / `filter: blur()`，配合 `animation: pulse 4s infinite alternate` 產生輕微呼吸光暈。
3. **Parallax Scroll**：背景 Orbs 元素在捲動時以不同速度移動，營造景深。
4. **Interactive Hover State**：滑鼠懸停在卡片或按鈕上時，附近的 Orbs 輕微加速或改變軌跡。
5. **Gradient Shift**：部分背景或文字使用 `linear-gradient`，並以慢速 `background-position` 動畫營造流動感。

### 構圖原則
- 稀疏而有層次：Orbs 不宜過密，注重空間感和錯落的層次。
- 柔和漸變：避免硬邊，多用 `radial-gradient` 和 `filter: blur()` 營造模糊、光暈效果。
- 深色背景襯托：以深色的背景（`--bg`）突出 Orbs 的發光感。
- 無邊框：不使用傳統邊框，改以顏色、透明度或光暈區分區域。
- 中心對齊或非對稱平衡：內容區塊可中心對齊，Orbs 則以非對稱方式營造動態平衡。

## 文案 voice

策展論述需呈現對「動態」與「無形」的探索，避免生硬的技術說明，強調藝術性和感官體驗：
- 避免直接陳述「本展覽 explores...」
- 強調動態、流動、無界限、沉浸感
- 用意象化的詞彙描述空間與時間的關係
- 少量英文詞彙點綴，提升國際感與現代感
- 避免使用終端機式引言或 ALL CAPS 副標，改用柔和的強調

---

## 互動行為

- Hero 區塊的大型 Orbs 緩慢浮動，並帶有輕微的呼吸光暈。
- 設計師卡片 hover 時，其周圍的小型 Orbs 會輕微加速或改變顏色。
- 講座排程表格的行在 hover 時，會有一條細微的光暈軌跡劃過。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- 頁面背景的 Orbs 以不同 `phase` 與 `speed` 持續移動，營造無盡循環。

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用所有 Orbs 浮動、光暈和軌跡動畫，僅保留靜態視覺。
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
