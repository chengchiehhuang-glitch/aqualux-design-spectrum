# M27 · Sticky 堆疊章節 / Sticky Stack

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page using the "Sticky Stack" motion aesthetic, where sections sequentially stack and push each other up, creating a continuous, layered narrative flow. This skill emphasizes smooth, performant scroll-driven animations inspired by modern product showcases.

### 色票


### 字型系統
- **Display（標題、巨型字）**：Inter 700/800 — 現代、清晰、具科技感
- **Body（內文、列表）**：Noto Sans TC 400/500 + Inter 400 — 簡潔易讀、中英搭配
- **Mono（meta、序號）**：Space Mono 400 — 結構化資訊、輕微科技感

### 動態效果
1. **Sticky Stack**：每個章節 `position: sticky`，`top: 0`。下一章節滾入時，會從底部將當前章節向上推動。
2. **Parallax Scroll**：背景元素（如大型編號、裝飾線）在滾動時以不同速度移動，營造景深。
3. **Element Fade-in**：新進入視窗的內容，如圖片或文字區塊，從透明度 0 逐漸淡入。
4. **Subtle Scale**：當章節被推入 sticky 狀態時，其內容可輕微縮放（如 0.98 -> 1）或提升 Z-index。
5. **Progress Indicator**: 側邊或頂部進度條，隨滾動指示當前章節。

### 構圖原則
- 大量留白，強調內容本身。
- 簡潔、俐落的線條和幾何形狀。
- 圖片與文字區塊清晰分離，形成模組化排版。
- 章節間透過堆疊動態自然過渡，而非硬性分隔線。
- 核心資訊以中央對齊或左對齊，保持視覺穩定。

## 文案 voice

策展論述聚焦於設計的本質與體驗，強調流暢性、結構與觀者互動。
- 使用清晰、直接的語言，避免過度修飾。
- 強調「體驗」、「流動」、「層次」等關鍵詞。
- 傳達一種經過精心策劃、無縫銜接的觀展感受。
- 中英文交錯，英文用於副標或關鍵概念強調，中文為主敘述。

## 互動行為

- 頁面滾動時，章節依序 `position: sticky` 於視窗頂部，並被後續章節從底部推動。
- 當一個新章節進入 sticky 狀態時，其內容（標題、圖片等）可有輕微的淡入或縮放動畫。
- 導航欄可固定在頂部，並根據當前 sticky 的章節高亮顯示。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。
- 圖片或內容區塊在首次進入視窗時，有平滑的淡入效果。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有滾動觸發的動畫、淡入、縮放效果，僅保留靜態堆疊。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- 使用 `will-change` 屬性優化關鍵動畫性能。
