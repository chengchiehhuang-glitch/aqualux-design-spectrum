# C14 · 賽博龐克 / Cyberpunk

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in full cyberpunk aesthetic — neon pink × electric cyan, scanlines, glitch typography, japanese katakana, holographic ticket mockup.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 c14 賽博龐克版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 20 張 gpt-image-2 生圖。整套素材 ~30 KB HTML + ~3 MB WebP（轉檔後）。

### 字型系統
- **Display（標題、Z01 巨型字）**：Orbitron 700/900 — 賽博龐克 wordmark 必備
- **Mono（meta、終端機、時間軸）**：JetBrains Mono 300/700
- **Body（內文）**：Noto Sans TC + PingFang TC
- **Japanese accent**：Noto Sans JP — 用片假名做次標、設計師名

### 動態效果
1. **Scanlines**：全屏 fixed overlay、`repeating-linear-gradient` 2px 黑紋、mix-blend-mode: multiply
2. **Glitch 標題**：`::before` `::after` 偽元素 + clip-path + RGB 偏移、3s 循環隨機抖動
3. **Aurora 背景**：5 個 radial-gradient ellipse、blur(80px)、慢速 transform 動態
4. **Grid 網格**：40×40px linear-gradient 微弱 cyan 線、固定背景
5. **Blink 游標**：`@keyframes blink 1.2s steps(2) infinite`

### 構圖原則
- 黑底為主、neon 為點綴（不要全屏螢光）
- 字大、字距大（letter-spacing 0.15-0.3em）
- 邊框少、用色帶+對比做分隔
- 切角裝飾用 `::before linear-gradient(135deg, transparent 50%, neon-pink 50%)`

## 文案 voice

賽博龐克的策展論述要**反 UX 學派** + **暗黑詩學**：
- 不要中性敘述（「這個展覽 explores...」）
- 要結構性對立（「Brutalist 跟 Glassmorphic 不只長相不一樣 — 它們對著兩種完全不同的受眾說話」）
- 用 > 終端機式引言、ALL CAPS 副標
- 中英夾雜（中文主敘述 + 英文 ALL CAPS 副標）
- 片假名做次標

## 互動行為

- Topbar `LIVE` 點閃爍 1.2s
- Hero glitch 標題 RGB 偏移每 3s 隨機抖動一次
- Aurora 5 個 ellipse 慢速 transform（28s loop）
- Scanlines fixed overlay 不隨滾動
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer terminal cursor `_` 閃爍 0.9s

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 glitch / scanlines / aurora
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
