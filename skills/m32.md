# M32 · 錯落淡入 / Fade Stagger

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with a refined, contemporary fade-in and staggered appearance, emphasizing content clarity and subtle, elegant motion.

## 視覺語彙

### 色票
```
--bg:        #fdfdfc   主背景（近白）
--paper:     #ffffff   卡片底（純白）
--ink:       #212121   主字（深灰）
--ink-light: #6a6a6a   次字（中灰）
--accent:    #7b68ee   強調色（丁香紫）
--accent-bg: rgba(123,104,238,0.08) 柔和強調背景
--line:      #e0e0e0   主線（淺灰）
--shadow-light: 0 4px 12px rgba(0,0,0,0.04) 輕柔陰影
```

### 字型系統
- **Display（標題、巨型字）**：Inter 700/800 — 現代、清晰，具備多種字重
- **Body（內文、列表）**：Noto Sans TC 400/500 — 易讀、簡潔
- **Mono（meta、日期）**：IBM Plex Mono 400 — 清晰、等寬

### 動態效果
1. **錯落淡入 (Fade Stagger)**：所有可見內容（區塊、卡片、文字行）在 `IntersectionObserver` 觸發時，以 `opacity: 0 -> 1` 及 `transform: translateY(20px) -> translateY(0)` 緩慢淡入。
   - `transition-property: opacity, transform;`
   - `transition-duration: 0.6s;`
   - `transition-timing-function: ease-out;`
   - `transition-delay: var(--stagger-delay);`
   - `var(--stagger-delay)` 每次遞增 50ms - 100ms。
2. **hover 輕微上浮**：卡片、按鈕等互動元素 `:hover` 時 `transform: translateY(-4px); transition: transform 0.2s ease-out;`
3. **頁面載入漸現**：`body` 在 `DOMContentLoaded` 後 `opacity: 0 -> 1`，`transition-delay: 0.2s; transition-duration: 0.8s;`

### 構圖原則
- 乾淨的白色/淺色背景，利用留白創造呼吸感。
- 內容區塊居中，最大寬度約 1080px。
- 資訊分層清晰，利用字重、字級、淺色線條做分隔。
- 適度使用輕柔的陰影 (`--shadow-light`) 增加層次感。
- 避免過多裝飾性元素，強調內容本身。

## 互動行為

- 頁面載入時，所有內容區塊從底部輕微上移並淡入。
- 導航連結、卡片、按鈕 hover 時有輕微的 `translateY` 上浮效果。
- 展區卡片點擊可展開更多資訊（此 demo 僅為視覺呈現）。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。

---

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有 `transition` 和 `transform` 動畫，僅保留 `opacity` 漸現，或完全禁用動效。
- `IntersectionObserver` 避免一次性渲染所有動畫，優化性能。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
