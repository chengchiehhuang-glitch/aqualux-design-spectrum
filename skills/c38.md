# M38 · 滑鼠光暈 / Cursor Spotlight

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Implements a dynamic "cursor spotlight" effect, where a radial gradient follows the user's mouse pointer, illuminating content and creating a focused, interactive experience.

## 視覺語彙

### 色票
```
--bg:          #0a0a0a   主黑底
--ink:         #f0f0f0   主文字色
--ink-secondary: #aaaaaa   次要文字色
--spotlight-core: #ffffff   光暈中心
--spotlight-edge: #a0c0ff   光暈邊緣
--accent-blue: #4a90e2   強調藍
--accent-green: #50e3c2   強調綠
```

### 字型系統
- **Display（標題）**：Inter 700/800 — 現代、清晰
- **Body（內文）**：Noto Sans TC + Inter 400/600 — 易讀、簡潔
- **Mono（code、meta）**：Fira Code 400 — 等寬、程式碼友善

### 動態效果
1. **Cursor Spotlight**：
    - 全屏 `::before` 偽元素，`pointer-events: none`
    - 背景設為 `radial-gradient`，中心透明，向外擴散為 `var(--spotlight-core)` 到 `var(--spotlight-edge)`
    - JavaScript 監聽 `mousemove` 事件，動態更新 CSS 自訂屬性 `--mouse-x` 和 `--mouse-y`
    - `background-position` 根據 `--mouse-x` `--mouse-y` 調整，使光暈中心跟隨滑鼠
    - `transition: background-position 0.05s ease-out` 創造平滑追蹤效果
2. **Hover 微互動**：卡片、按鈕等元素在光暈經過時，會有輕微的 `transform: translateY(-2px)` 或 `box-shadow` 變化，加強互動感。
3. **Fade-in 效果**：頁面載入時，內容元素緩慢淡入，提升視覺流暢度。

### 構圖原則
- 簡約、現代、留白多
- 內容區塊清晰，利用光暈引導視線
- 少量且精緻的動畫，不喧賓奪主
- 避免過多裝飾，強調資訊本身

## 文案 voice

簡潔、現代、引人入勝。強調「探索」、「聚焦」、「洞察」等詞彙，呼應光暈效果。

- 鼓勵使用者透過互動探索內容。

## 互動行為

- **Cursor Spotlight**：全頁面背景光暈追蹤滑鼠移動。
- **Nav Hover**：導覽列項目滑鼠懸停時，文字顏色變亮，下方出現細微底線動畫。
- **Card Hover**：設計師卡片、展區卡片、票務卡片滑鼠懸停時，輕微上浮 `transform: translateY(-3px)` 並增加 `box-shadow`。
- **Button Click**：按鈕點擊時，輕微下壓 `transform: translateY(1px)`。
- **Scroll Reveal**：區塊內容滾動進入視窗時，緩慢淡入並向上移動。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce`：
    - 禁用 Cursor Spotlight 效果，背景恢復為純色。
    - 禁用所有 Hover 效果的 `transform` 和 `transition`。
    - 禁用 Scroll Reveal 動畫。
- Table `<th>` 標記欄位。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~90% 大小縮減）。
- JS 監聽 `mousemove` 事件使用 `requestAnimationFrame` 進行優化，避免卡頓。
- 光暈效果的 CSS `will-change: background-position` 提升渲染性能。

## 衍生提示（給其他 Skills 模仿）

此 Skill 的核心是透過動態視覺效果來引導使用者注意力。其他 Skills 可以借鑒這種**「引導式互動」**的設計理念：
- **Parallax Scrolling**：利用不同層次滾動速度差異，引導視線。
- **Focus States**：設計更具視覺衝擊力的焦點狀態，引導鍵盤使用者。
- **Interactive Backgrounds**：背景元素隨使用者輸入（如滾動、點擊）產生變化，創造沉浸感。
