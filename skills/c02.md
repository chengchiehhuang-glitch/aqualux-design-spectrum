# C02 · 新擬物化 / Neumorphism

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in the soft-extruded plastic look — single-tone backgrounds, paired inner/outer shadows, embossed buttons, pillowy surfaces, monochrome restraint.

## 視覺語彙

### 色票
```
--bg:           #e6e9ef   主底（同色系展開的關鍵單一基色）
--bg-deep:      #d4d8e0   稍深底（凹陷區）
--bg-soft:      #ecf0f6   稍淺底（凸起區）
--shadow-dark:  #b8bcc6   外凸右下陰影
--shadow-light: #ffffff   外凸左上高光
--ink:          #2a2f3a   主字（避免純黑）
--ink-2:        #5a6070   次字
--ink-3:        #8a909c   弱字
--accent:       #6c7cff   柔紫藍 accent（最低限度使用）
--accent-soft:  #d8dcff   accent 弱底
--surface-1:    9px 9px 18px #b8bcc6, -9px -9px 18px #ffffff   外凸
--surface-2:    inset 6px 6px 12px #b8bcc6, inset -6px -6px 12px #ffffff   凹陷
```

### 字型系統
- **Display（標題、Hero）**：Nunito 700/800，圓潤幾何 sans — 與膨脹感呼應
- **Mono（meta、座標、票券序號）**：JetBrains Mono 400
- **Body（內文）**：Nunito 400/600 + Noto Sans TC 400
- **Numerals**：Nunito tabular-nums，避免細襯線

### 動態效果
1. **Press-in 切換**：button active 時從 `--surface-1`（凸）切到 `--surface-2`（凹），180ms ease-out
2. **Hover halo**：卡片 hover 時 shadow 範圍增加 +3px、亮度提高、模擬靠近光源
3. **Embossed text**：標題 `text-shadow: 1px 1px 0 #fff, -1px -1px 0 #b8bcc6` 浮雕字
4. **Soft toggle**：toggle switch 軌道內凹、把手外凸、切換有彈性 cubic-bezier(0.34,1.56,0.64,1)
5. **No hard borders**：所有邊界用 shadow 雙向構成、零 1px border
6. **Subtle hue shift**：accent 元件 hover 時飽和度 +10%、180ms

### 構圖原則
- **整頁同色系**：背景與卡片只差 2-3% 明度，靠陰影區分層次
- 卡片 border-radius: 20-32px（流派典型超大圓角）
- 陰影必須**成對**：外凸=右下深+左上亮、凹陷=右下亮+左上深
- 文字對比度永遠是挑戰：低對比配色容易掉到 AA 以下，必須額外校驗
- 元件之間留 ≥ 24px 空白，否則陰影會疊到鄰居

## 文案 voice

新擬物化的策展論述要**柔和 + 觸覺感**：
- 用「按下、按起、浮、沉、壓」這類觸覺動詞
- 強調「介於擬真與抽象之間」這個流派的核心張力
- 句子可以稍微長一點、有呼吸感（跟視覺的圓潤呼應）
- 不用 ALL CAPS 副標（會破壞柔和氣質），改用 Title Case 英文小標
- 引言可寫「Touch what isn't there.」這類短句
- 中文不用「戰場 / 引擎」硬詞，改用「面、層、觸、輕」

## 互動行為

- Button active 時 surface-1 切換到 surface-2（凸→凹），180ms
- 卡片 hover 陰影擴張 +3px、亮度提高
- Toggle 切換用 cubic-bezier(0.34,1.56,0.64,1) 帶輕微彈跳
- 票券 featured 卡持續呼吸（scale 1 → 1.015 → 1，4s loop）
- PURCHASE 按鈕 `disabled aria-label="Demo only — not for sale"`
- 表單 input 也是內凹樣式、focus 時 accent halo 浮現

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用呼吸、彈跳、所有 transform 動畫
- **新擬物化的最大 a11y 風險是對比不足**：`--ink` on `--bg` 必須 ≥ 7:1（AAA），因為陰影分隔本身會吃掉部分知覺對比
- Button、Input、Toggle 必須有明確 focus ring（不能只靠 surface-2 凹陷態，screen reader 看不到）
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP
- 多陰影成本：避免在一頁超過 ~40 個 surface-1 元件，否則 paint 成本爆掉

## 衍生提示

C02 是「擬真但極簡」的代表。延伸方向：
- 配色從藍灰改成奶油杏 → 觸覺溫度上升、偏向北歐 craft
- 加入 1 個鮮明 accent（如橘） → 跟主流派拉開距離、變得更年輕
- 結合 c01 玻璃 → 浮在玻璃上的凸起按鈕、混合質感

骨架不變、單色基底換色 + 陰影成對規則保留 = 同流派多色變體。
