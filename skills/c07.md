# C07 · Y2K 千禧 / Y2K

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in early-2000s techno-optimist aesthetic — bubble-chrome 3D type, frosted blue + ice silver, lens flares, inflatable UI, dial-up modem energy, iMac G3 candy colors, "the future is going to be smooth and shiny" vibe.

### 字型系統

- **Display（標題、Hero）**：Eurostile Extended / Bank Gothic / Microgramma — Y2K 標誌性「未來感」展示字；fallback `Orbitron 700`
- **Bubble accent**：Chicago / VAG Rounded — 圓潤泡泡字體用在按鈕
- **Mono（meta、座標）**：Monaco / Andale Mono
- **Body（內文）**：Verdana 400 + Noto Sans TC 400（Y2K 時代 web 標配）
- **Numerals**：Eurostile lining-nums

### 動態效果

1. **Chrome bubble buttons**：所有 button 都是橢圓 + 上半部 white-to-transparent gradient + 下半部 ice-blue 漸層 + 陰影
2. **Lens flare**：hero 角落出現 SVG 多邊形 lens flare + 光暈
3. **Y2K shine sweep**：標題或卡片上有 diagonal white shine 動畫 4s 重複（典型「光劃過按鈕」效果）
4. **Inflatable hover**：按鈕 hover scale 1.05 + 陰影擴張，像吹氣球
5. **Holographic gradient**：accent 元件用 conic-gradient 模擬 iridescent 全息色
6. **Cursor trail**：滑鼠移動留下漸淡的星星或泡泡（Geocities 致敬）
7. **Marquee `<marquee>`-style**：footer 用 CSS 動畫模仿 90s marquee tag、跑「>>> ENTER THE FUTURE <<<」

### 構圖原則

- 大量「玻璃 + 鉻」混合：背景冰藍透明感、前景元件鉻金鏡面
- 圓角極端：button 用 50%（完全橢圓）、card 用 16-24px
- 元件**膨脹**：所有東西看起來像吹過氣
- 色彩用「iMac G3 candy」5 色（粉藍綠紫橘）做 accent 系列
- Lens flare、light burst、sparkle 大方使用
- 排版可以不對齊（這時代沒 grid system）— 故意微歪斜

## 文案 voice

Y2K 的策展論述要**未來樂觀 + 童趣 + 雜誌封面廣告腔**：
- 句子像 2001 年雜誌封面 hype 標語：「歡迎來到未來」
- 用「介面 / 通訊 / 數位 / 全球 / 連線」這類千禧前後流行的科技關鍵詞
- 標題像 PC 雜誌：「設計光譜 2026：未來，已連線」
- 副標可全大寫但要圓潤字體（Eurostile）、不像 c14 那麼硬
- 引言可寫得有點過時但真誠的科技樂觀腔：「我們相信介面會更友善、世界會更近、設計能讓人微笑」
- 拒絕當代「諷刺式」幽默 — 千禧前後是「真心相信未來」的時代，文案要 honor 那個氣質

## 互動行為

- Hero shine sweep 每 4s 從左到右掃過標題
- 按鈕 hover scale 1.05 + 光暈擴張（吹氣球效果）
- LIVE 旋轉地球 icon 8s 旋轉一圈
- 鼠標移動產生淡色泡泡 trail（500ms fade out）
- 票券 featured 卡 holographic conic-gradient 緩慢旋轉
- Footer marquee 連續跑「>>> ENTER THE FUTURE / AQUALUX 2026 / DESIGN SPECTRUM <<<」
- PURCHASE 按鈕 `disabled aria-label="Demo only — not for sale"`

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 shine sweep、地球旋轉、鼠標 trail、marquee、holographic rotate
- 冰藍底 + 深海軍字 對比驗證需 ≥ 4.5:1（`#1a2a4a` on `#d6e7ff` 大約 9:1，過關）
- 鉻金面上文字要小心對比下降（多層 gradient 可能讓部分位置字看不清）
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP
- 過量 gradient + box-shadow 注意 paint 成本，shine 動畫用 `transform: translateX` 而非 `background-position`

## 衍生提示

C07 是「iMac G3 / Windows XP Luna / Frutiger Aero 前身」家族。延伸方向：
- 加重水滴 + 自然光暈 → 走 Frutiger Aero（2003-2013 後期 Y2K）
- 拉高飽和度 + 加片假名 → 跟 c06 蒸氣波交叉、做「Y2K vaporwave」
- 換成深底 holographic → cyber Y2K（黑底 + chrome + rainbow）

骨架不變、ice-blue 換 candy 色比例 = 多種 Y2K 變體。
