### 字型系統
- **Display（標題、巨型字）**：Inter Variable 700/800 — 現代、清晰、高辨識度
- **Body（內文、列表）**：Inter Variable 400/500
- **Mono（meta、時間軸）**：JetBrains Mono 300/700 — 用於程式碼或數據展示
- **TC Fallback**：Noto Sans TC + PingFang TC

### 動態效果
1.  **Magnetic Attraction**：所有互動元素（按鈕、連結、卡片）在鼠標靠近時，透過 JavaScript 計算 `linear interpolation` 或 `spring physics`，產生輕微的位移和旋轉。位移量與距鼠標的距離成反比。
2.  **Subtle Hover State**：磁吸元素在鼠標懸停時，背景色或邊框產生輕微的顏色變化 (`--accent-hover`)，並伴隨細微的 `scale(1.02)` 放大效果。
3.  **Touch Fallback**：在觸控設備上，磁吸效果轉化為 `tap feedback`，即輕觸時元素輕微縮放或變色，避免冗餘的位移。
4.  **Cursor Trail**：一個極其輕微、半透明的圓形或光點，會在鼠標移動時在畫面中留下短暫的殘影，增加互動感。
5.  **Smooth Scrolling**：全頁面採用 `scroll-behavior: smooth`，提供流暢的導航體驗。

### 構圖原則
- **清晰留白**：大量運用負空間，確保每個元素都能「呼吸」。
- **秩序網格**：基於強大的網格系統，確保元素對齊和間距一致。
- **層次分明**：透過字重、顏色深淺和輕微的陰影 (`--shadow`) 建立視覺層次。
- **無圓角化**：所有互動元件和區塊保持銳利直角 (`border-radius: 0`)，強化現代感和精準度。
- **髮絲線分隔**：主要區塊之間使用 1px 的 `--line` 顏色髮絲線進行分隔，而非強烈的邊框或色塊。

## 文案 voice

文案語氣應保持**專業、精煉、具引導性**。避免過度誇飾，強調設計的精準與互動的細膩。
- **Operator 視角**：以「我們如何打造」而非「這是一個」的語氣，強調技術實作與使用者體驗的核心。
- **引導式敘述**：文案應鼓勵使用者探索，例如「輕觸或懸停，感受設計的脈動。」
- **簡潔有力**：避免冗長描述，直接點出功能與價值。
- **中英夾雜**：中文主敘述，關鍵術語或強調句可使用英文。

---

## 互動行為

- **Magnetic CTA**：所有 `.magnetic-target` 元素綁定 JavaScript 監聽鼠標位置，計算位移量並應用 `transform: translate()`。
- **Hover Feedback**：`--accent-hover` 顏色變化與 `scale(1.02)` 效果透過 CSS `transition` 實現。
- **Touch Device Fallback**：檢測 `ontouchstart` 事件，若為觸控設備則關閉鼠標磁吸效果，改為輕觸時的 `active` 狀態縮放。
- **Cursor Trail**：一個絕對定位的 `div` 元素，其 `top` 和 `left` 屬性跟隨鼠標，並在一段時間後 `opacity` 漸變為 0。
- **Purchase Buttons**：按鈕現為 `disabled aria-label="Demo only — not for sale"`，但其磁吸效果應保持啟用。

---

## a11y / 性能

- `<main>` landmark 包所有主內容，確保結構語義。
- `prefers-reduced-motion: reduce`：如果用戶設置了減少動態偏好，則完全禁用磁吸效果和 cursor trail，僅保留靜態 hover 狀態。
- Table `<th scope="col">` 標欄，提升表格可訪問性。
- 圖片全部 `loading="lazy" decoding="async"`，優化加載性能。
- 全 PNG 轉 WebP（~91% 大小縮減），減少資源體積。
- 磁吸效果的 JS 採用 `requestAnimationFrame` 進行優化，避免主線程阻塞。
