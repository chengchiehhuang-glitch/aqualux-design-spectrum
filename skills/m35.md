# M35 · 極光漸層流動 / Aurora Flow

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with an immersive aurora flow aesthetic — soft, shifting radial gradients, ethereal blurs, and gentle motion, creating an ambient, dreamlike experience.

### 字型系統
- **Display（標題、Z01 巨型字）**：Montserrat 500/700 — 現代、清晰，但有柔和感
- **Mono（meta、終端機、時間軸）**：Fira Code 300/500 — 程式碼風格，但較為圓潤
- **Body（內文）**：Noto Sans TC + PingFang TC
- **Accent**：Playfair Display Italic — 用於引言、強調句，增加優雅感

### 動態效果
1. **Aurora 背景**：全屏 `fixed` overlay，多個 `radial-gradient` 橢圓形，`blur(100px)`，`transform` 慢速 `loop` 動畫，`mix-blend-mode: screen`
2. **文本漸變**：部分標題文字應用 `linear-gradient` 文本填充，顏色隨背景 Aurora 變化
3. **卡片懸浮**：卡片 `hover` 時微幅 `translateY` 提升，`box-shadow` 擴散，`transition` 0.4s
4. **流動光標**：`::after` 偽元素作為光標，緩慢 `opacity` 閃爍，顏色漸變
5. **按鈕微光**：按鈕 `hover` 時，內部 `::before` 偽元素做 `radial-gradient` 從中心向外擴散的微光效果

### 構圖原則
- 深色底為主，漸層光暈為點綴，避免過度飽和
- 大面積留白或留黑，營造空間感與沉浸感
- 文字排版注重層次與呼吸感，避免過密
- 元素之間以柔和的漸層或模糊效果連接，而非硬邊框
- 構圖偏向流動與非對稱，營造動態美感

## 文案 voice

Aurora Flow 的策展論述要**詩意、沉浸** + **探索動態的本質**：
- 不要直接的口號式敘述
- 要引導思考，強調流動、變幻、無界限的設計哲學
- 用柔和的語氣，避免尖銳的對比
- 中英夾雜（中文主敘述 + 英文子標題或關鍵詞）
- 少量英文形容詞點綴，強調氛圍

## 互動行為

- Topbar `LIVE` 點柔和漸變閃爍 1.8s
- Hero 標題文字漸變色塊，隨背景 Aurora 緩慢變化
- Aurora 5 個 ellipse 慢速 transform（45s loop），營造永恆流動感
- 全屏 Aurora 背景 `fixed` overlay，不隨滾動
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer terminal cursor `_` 緩慢 `opacity` 閃爍 1.5s

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用所有 Aurora 背景動畫及文本漸變
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
