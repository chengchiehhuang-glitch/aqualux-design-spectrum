# C15 · 構成主義 / Constructivism

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in full Constructivism aesthetic — bold red, black, white, and yellow, dynamic diagonals, layered geometric shapes, propaganda poster typography.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 c15 構成主義版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 20 張 gpt-image-2 生圖。整套素材 ~30 KB HTML + ~3 MB WebP（轉檔後）。

## 視覺語彙

### 色票
```
--primary-red:    #E0162B   主強調紅
--secondary-black: #1A1A1A   深黑背景/文字
--accent-yellow:  #F7D002   輔助黃
--ink-white:      #F0F0F0   主要文字/背景
--dark-grey:      #4A4A4A   次要文字/背景
```

### 字型系統
- **Display（標題、巨型字）**：Oswald 700/900 — 粗獷、壓縮，具宣傳海報感
- **Mono（meta、座標、時間軸）**：Roboto Mono 400/700 — 簡潔、機械感
- **Body（內文）**：Noto Sans TC + PingFang TC — 現代、易讀
- **Accent（次標、設計師名）**：Bebas Neue — 細長、醒目

### 動態效果
1. **Diagonal Slices**: 全頁面多處使用 `clip-path: polygon(...)` 或 `transform: skewY(...)` 創造斜切區塊。
2. **Layered Geometry**: 區塊、圖片、文字以 z-index 錯位堆疊，形成深度感。
3. **Bold Transitions**: 區塊間以 stark 的顏色對比與銳利邊緣分隔，而非柔和漸變。
4. **Subtle Motion**: 導覽列或互動元素 hover 時，僅有快速的顏色反轉或輕微位移，不使用複雜動畫。
5. **Static Background**: 背景保持簡潔，主要視覺動態來自前景元素的構成。

### 構圖原則
- 強調對角線、幾何形狀（矩形、三角形、圓形）的重複與組合。
- 大膽的紅、黑、白、黃對比，營造視覺衝擊力。
- 文本與圖像緊密整合，文字本身成為設計元素。
- 資訊層次清晰，排版如同宣傳海報，直接且具影響力。
- 留白空間少，元素填滿版面，創造密集感。

## 頁面結構（8 區段）

```
1. Topbar           簡潔的標題 + 日期（紅底白字）
2. Hero             巨型斜切標題 + 展覽資訊（紅黑白黃交錯）
3. § 策展論述       文本區塊與幾何形狀交錯，重點文字用黃色強調
4. § 設計師名單     12 張幾何抽象頭像卡片，紅黑白黃為主

6. § 五大展區       Z01-Z05 大型數字編號，配幾何圖形與區塊說明
7. § 講座排程       簡潔表格，紅黑白對比

9. Footer           版權資訊，簡潔的幾何分隔線
```

## 文案 voice

構成主義的策展論述應**直接、具宣言性、強調結構與功能**：
- 語言簡潔有力，避免冗長修飾。
- 強調設計的「建造」與「構成」過程。
- 使用粗體、大寫來強調重點。
- 文本排版本身即是設計的一部分，與視覺元素融合。
- 偶爾使用號召性語句，如同宣言。

---

## 互動行為

- 導覽列項目 hover 時，背景色快速從黑變紅，文字變白。
- 區塊間的斜切邊界保持靜態，不隨滑鼠移動。
- 圖片區塊 hover 時，邊框顏色從黑變黃，無縮放或位移。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- 頁面滾動時，部分幾何背景元素可能會有輕微的視差效果，但整體構成不變。

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用所有非必要的動態效果，僅保留靜態構成。
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
