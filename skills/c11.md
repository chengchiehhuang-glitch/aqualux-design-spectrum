# C11 · 包浩斯 / Bauhaus

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in full Bauhaus aesthetic — primary colors, geometric shapes, sans-serif typography, grid layouts, and functional design.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 c11 包浩斯版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 5-10 張 gpt-image-2 生圖。整套素材 ~30 KB HTML + ~3 MB WebP（轉檔後）。

## 視覺語彙

### 色票
```
--bg:        #f0f0f0   主背景灰白
--bg-card:   #ffffff   卡片底白
--primary-red: #e30022   主強調紅
--primary-blue: #004586   次強調藍
--primary-yellow: #f8d210   點綴黃
--ink:       #212121   主字黑
--ink-2:     #666666   次字灰
--line:      #cccccc   分隔線
```

### 字型系統
- **Display（標題、Z01 巨型字）**：Futura Bold / Medium — 幾何無襯線字體代表
- **Mono（meta、終端機、時間軸）**：IBM Plex Mono — 具現代感的等寬字體
- **Body（內文）**：Noto Sans TC + Helvetica Neue — 清晰簡潔的無襯線字
- **Japanese accent**：Noto Sans JP — 用片假名做次標、設計師名

### 動態效果
1. **Grid Overlay**：全屏 fixed overlay、`linear-gradient` 1px 細線網格、`mix-blend-mode: soft-light`
2. **Shape Transition**：區塊載入時，元素以簡單的幾何（圓、方、三角）從中心擴散或位移
3. **Subtle Hover**：點擊區塊時，背景色塊輕微變色或邊框加粗，無陰影
4. **Geometric Loader**：載入動畫為旋轉或變形的幾何圖形（紅黃藍）
5. **Typewriter Effect**：關鍵文字塊以打字機效果逐字顯現

### 構圖原則
- **網格系統**：嚴格的水平垂直網格，強調秩序與功能性
- **幾何形狀**：大量使用圓、方、三角作為設計元素和區塊分割
- **三原色點綴**：紅、黃、藍作為視覺焦點，但以黑白灰為主色調
- **簡潔留白**：強調空間感，避免過度裝飾，功能優先
- **字體即設計**：字體本身就是重要的視覺元素，而非單純承載信息

## 文案 voice

包浩斯的策展論述要**強調功能性、結構與普遍性**：
- 不要過度感性或隱喻，直接點出設計的本質
- 強調形式追隨功能、材料的誠實運用
- 用清晰、直接的語言，避免花哨
- 結構性對立可以有，但目的是為了清晰闡述設計原則
- 中文主敘述，英文標題或副標，避免片假名（除非與特定設計師相關）

---

## 互動行為

- Grid Overlay 保持靜態，不隨滾動
- Shape Transition 每次載入或點擊新區塊時觸發一次
- Subtle Hover 效果應簡潔，無複雜動畫
- Geometric Loader 在頁面載入初期或內容切換時顯示
- Typewriter Effect 用於策展論述的關鍵句，每次只播放一次

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 Shape Transition 和 Typewriter Effect
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
