# C01 · 玻璃擬態 / Glassmorphism

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page as a frosted-glass interface — translucent panels, soft pastel gradients beneath, hairline borders, gentle backdrop-blur, optical depth without weight.

## 視覺語彙

### 色票
```
--bg:           #eef2fb   主底（極淺霧藍）
--bg-grad-a:    #ffb1d8   背景漸層 A（粉紅）
--bg-grad-b:    #a8d8ff   背景漸層 B（淺藍）
--bg-grad-c:    #c4b5fd   背景漸層 C（薰衣草）
--glass:        rgba(255,255,255,0.45)  玻璃面
--glass-deep:   rgba(255,255,255,0.62)  強調玻璃面
--glass-border: rgba(255,255,255,0.55)  玻璃內緣高光
--glass-edge:   rgba(255,255,255,0.18)  玻璃外緣陰影
--ink:          #1d2233   主字
--ink-2:        #4d5570   次字
--ink-3:        #8089a3   弱字（meta）
--accent:       #5e8bff   藍色 accent
--shadow-soft:  0 8px 32px rgba(31,38,135,0.12)
```

### 字型系統
- **Display（標題、Hero）**：Inter 600/700，letter-spacing -0.02em — 現代 SF Pro 質感
- **Mono（meta、coord、票券序號）**：JetBrains Mono 400
- **Body（內文）**：Inter 400 + Noto Sans TC 400
- **Subtle accent**：Inter italic 用於英文副標、引言

### 動態效果
1. **Backdrop-blur 玻璃**：`backdrop-filter: blur(20px) saturate(180%)`、所有卡片與 nav 必備
2. **Aurora 背景漸層**：3-5 個大型 radial-gradient blob、慢速 transform 漂移（45s loop）
3. **Hover lift**：卡片 hover translateY(-4px) + 陰影加深、150ms ease-out
4. **Inner light edge**：`inset 0 1px 0 rgba(255,255,255,0.6)` 模擬玻璃上緣折光
5. **Parallax depth**：scroll 時背景 blob 與前景卡片以不同 transform speed 移動
6. **Frosted ripple**：按鈕 active 時短暫加 `backdrop-filter: blur(30px)` 100ms
7. **Edge specular**：卡片右上角微 highlight，2px 對角白色 → transparent

### 構圖原則
- 背景永遠有色彩（不是純白）— 玻璃需要底色才看得出折射
- 卡片 border-radius: 24px（流派典型大圓角）
- 多層堆疊：背景 blob → 第一層卡片 → 第二層浮窗 → 文字
- 邊框極細：1px `--glass-border`，配合 inset 高光做雙線效果

## 文案 voice

玻璃擬態的策展論述要**通透 + 高科技清涼感**：
- 句子要乾淨、不擠、留白比賽博龐克多
- 用「透視 / 層疊 / 折射 / 介面 / 半透明」這類光學詞彙做隱喻
- 標題用「設計光譜：透視十二位設計師的折射軌跡」這類視覺隱喻
- 中英並陳但中文主敘述，英文副標用 Inter italic 小字、不全大寫
- 引言段落像 Apple keynote 旁白 — 短、靜、肯定句、句末不加感嘆
- 不用「賽博 / 引擎 / 戰場」這類硬詞，改用「層、面、光、空氣」

## 互動行為

- Topbar 隨 scroll 從 `blur(8px)` 漸變至 `blur(24px)`
- Aurora 3-5 個 ellipse 慢速 transform（45s loop）
- 卡片 hover translateY(-4px) + shadow 加深 150ms ease-out
- Z01-Z05 卡片在 viewport 進入時、IntersectionObserver 觸發 fade-up
- 票券 featured 卡 hover 額外加 `backdrop-filter saturate(220%)`
- PURCHASE 按鈕 `disabled aria-label="Demo only — not for sale"`

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 aurora 動態、卡片 hover lift、parallax
- 玻璃面對比度需確認 ≥ AA：`--ink` on `--glass` 需 ≥ 4.5:1
- 文字**絕不**直接放在純漸層上（必須在玻璃面上）
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
- backdrop-filter fallback：`@supports not (backdrop-filter)` 改用 `rgba(255,255,255,0.85)` solid 底
