# M33 · 打字機標題 / Typewriter

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with a classic typewriter aesthetic — monochromatic tones, monospace fonts, and a captivating character-by-character text reveal.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 m33 打字機標題版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 20 張 gpt-image-2 生圖。整套素材 ~30 KB HTML + ~3 MB WebP（轉檔後）。

## 視覺語彙

### 色票
```
--bg:        #f0f0e8   主紙色
--bg-card:   #e8e8df   卡片底
--ink:       #2c2c2c   主字墨色
--ink-light: #5c5c5c   次字墨色
--ink-faded: #8c8c8c   淡墨色
--accent:    #a020f0   紫墨水（強調）
--line:      #d0d0c8   分隔線
```

### 字型系統
- **Display（標題、巨型字）**：Special Elite / New Courier — 打字機標誌性字體
- **Mono（meta、終端機、時間軸、內文）**：IBM Plex Mono / Courier Prime — 經典等寬字體
- **Body（內文）**：Noto Serif TC / Lora — 復古襯線字體
- **Japanese accent**：Noto Sans JP — 用片假名做次標、設計師名

### 動態效果
1. **Char-by-char reveal**：文字逐字出現，模擬打字機敲擊效果，`steps(1)` CSS animation
2. **Blinking caret**：內容輸入完畢後，在最後一個字元後方顯示閃爍游標 (`_` 或 `█`)
3. **Paper texture**：全屏 `fixed` overlay，`background-image: url('noise.png')` 或 `radial-gradient` 模擬紙張纖維
4. **Scroll snap**：區段滾動時，頁面平滑地對齊到各區段頂部，模擬文件切換
5. **Typewriter sound**：JS 觸發打字機音效，可選開啟/關閉

### 構圖原則
- 頁面邊界寬闊，模擬書寫邊距
- 章節分隔使用單純的虛線或細實線，或留白
- 圖片邊框為簡單的細線框，無陰影
- 標題與內文對齊，視覺上呈現規整的文字塊
- 避免複雜漸層與陰影，一切以「紙上印刷」為基底考量

## 文案 voice

策展論述要**嚴謹、精煉，帶有學術報告的語氣**，但又不失策展的引導性：
- 避免浮誇，用詞精準，如同報告或期刊文章
- 強調「解構」、「歸檔」、「分析」等詞彙
- 引用風格使用縮進，並以等寬字體呈現
- 中英夾雜，英文多用於專業術語或強調關鍵概念
- 敘述風格仿照學術論文的「引言」或「摘要」

## 互動行為

- 所有主要文字內容（標題、內文、列表）以 `char-by-char` 方式逐字顯示
- 每個 `char-by-char` 區塊結束後，最後一個字元後方會有 `_` 游標閃爍 0.8s
- 頁面滾動時，背景的 `paper texture` 靜止不動 (fixed)
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- 頁面載入時，可選播放一次短促的打字機音效
- `[LIVE]` 點閃爍 0.9s

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 `char-by-char` 動畫、閃爍游標、`scroll-snap`
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
- 考慮文字動畫對閱讀障礙用戶的影響，提供簡潔的靜態版本
