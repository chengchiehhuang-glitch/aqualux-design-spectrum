# C13 · 故障藝術 / Glitch Art

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in full glitch art aesthetic — RGB split, scanlines, data mosh, pixelation, and digital artifacts.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 c13 故障藝術版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 20 張 gpt-image-2 生圖。整套素材 ~30 KB HTML + ~3 MB WebP（轉檔後）。

### 色票
```

--bg-card:   #1a1a1a   卡片底

--glitch-green:#00ff99  RGB綠偏移
--glitch-blue:#0099ff  RGB藍偏移
--glitch-purple:#cc00ff 隨機干擾色
--glitch-yellow:#ffcc00 隨機干擾色
--ink:       #e0e0e0
--ink-2:     #a0a0a0
--ink-3:     #606060
```

### 字型系統
- **Display（標題、Z01 巨型字）**：VT323 400/700 — 像素化、終端機感
- **Mono（meta、終端機、時間軸）**：Press Start 2P 400
- **Body（內文）**：Noto Sans TC + PingFang TC
- **Japanese accent**：Dotumche (點陣字體) — 用片假名做次標、設計師名

### 動態效果
1. **RGB Split**：全屏 `::before` `::after` 偽元素 + `mix-blend-mode: screen` + `filter: blur(1px)` + 隨機 `transform: translate()` 偏移，3-5s 循環隨機抖動
2. **Scanlines**：全屏 fixed overlay、`repeating-linear-gradient` 2px 黑紋、`mix-blend-mode: overlay`
3. **Data Mosh**：部分區塊 `filter: saturate(200%) hue-rotate(90deg) contrast(150%)` 隨機疊加，短暫出現（0.2s）
4. **Pixelation**：圖片 hover 時 `filter: pixelate(2px)` 效果
5. **Static Noise**：背景 `background-image: url(noise.png)` 微弱隨機雜訊，`mix-blend-mode: overlay`
6. **Text Glitch**：標題文字 `text-shadow` 多層偏移，隨機 `clip-path` 裁剪，1s 循環隨機抖動

### 構圖原則
- 深色底為主，高對比的 RGB 偏移色作為點綴
- 資訊塊之間用強烈的數位失真效果（如破碎線條、色塊偏移）分隔
- 標題文字大、有強烈視覺衝擊力，字距不規則
- 圖片邊緣常有像素化或失真處理
- 善用不規則形狀、錯位排版來營造故障感

## 文案 voice

故障藝術的策展論述要**反完美主義** + **擁抱錯誤美學**：
- 不要中性敘述（「這個展覽 explores...」）
- 要結構性對立（「像素的堆疊與數據的崩壞，不只是視覺的顛覆 — 更是對數位完美主義的嘲諷」）
- 用 `> 數據流引言`、`[ERROR] ALL CAPS 副標`
- 中英夾雜（中文主敘述 + 英文 ALL CAPS 副標）
- 點陣片假名做次標

## 互動行為

- Topbar `RANDOMIZING` 點閃爍 0.8s
- Hero glitch 標題 RGB 偏移與隨機裁剪每 1-2s 抖動一次
- 全屏 RGB Split 隨機 `transform: translate()` 每 3-5s 抖動一次
- Scanlines fixed overlay 不隨滾動
- PURCHASE 按鈕現為 `disabled aria-label="[ERROR] DEMO MODE ONLY"`
- Footer terminal cursor `█` 閃爍 0.7s，並隨機出現單字符亂碼

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 RGB Split / Scanlines / Data Mosh / Text Glitch
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
