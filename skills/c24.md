# C24 · 手繪塗鴉 / Hand-Drawn Sketch

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in a whimsical hand-drawn sketch aesthetic — crayon scribbles, wobbly lines, playful arrows, and a touch of childlike joy.

---


### 字型系統
- **Display（標題、Z01 巨型字）**：Patrick Hand SC 400 — 帶有手寫感的標題字
- **Mono（meta、終端機、時間軸）**：Caveat 400/700 — 輕鬆隨意的筆記感
- **Body（內文）**：Noto Sans TC + PingFang TC
- **Handwritten accent**：Kalam 300/700 — 用來做隨意註解、設計師名

### 動態效果
1. **Wobbly Lines**：所有邊框、分隔線用 `border-image` 或 `background-image` 模擬手繪不規則線條，`@keyframes` 輕微晃動。
2. **Scribble Underline**：標題、重要文字下方用 `::after` 偽元素，`background-image` 模擬蠟筆塗鴉底線，`animation: scribble 1.5s infinite alternate;`
3. **Paper Texture Overlay**：全屏 fixed overlay，`background-image` 模擬輕微紙張紋理，`mix-blend-mode: multiply` 或 `overlay`。
4. **Sketchy Arrows**：連結、導航圖示替換為手繪風格箭頭 SVG，`transform: rotate(-5deg)` 輕微歪斜。
5. **Crayon Pop-in**：元素載入時，用 `transform: scale(0.8) rotate(5deg); opacity: 0;` 到 `scale(1) rotate(0deg); opacity: 1;` 模擬輕快的手繪登場。

### 構圖原則
- 淺色紙白底為主、蠟筆色為點綴（不要全屏高飽和）
- 字體大小適中、行距寬鬆（line-height 1.6-1.8）
- 邊框少、用手繪線條和不規則形狀做分隔
- 元素輕微歪斜、不完全對齊，增加手繪隨意感（`transform: rotate(var(--angle))`）

## 文案 voice

手繪塗鴉的策展論述要**輕鬆、隨意、充滿好奇心**：
- 不要嚴肅的學術用語
- 要像筆記本上的隨手塗鴉，充滿個人感
- 用手寫感引言、隨意圈畫重點
- 像講故事一樣，帶著探索的語氣

---

## 互動行為

- Topbar `LOGO` 輕微晃動 1.5s
- Hero 標題下方蠟筆底線輕微「塗抹」動畫
- Paper Texture Overlay 固定不隨滾動
- 隨意箭頭 `transform: rotate(var(--angle))` 輕微抖動
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer 筆記本提示 `_` 閃爍 1.0s

## a11y / 性能

- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
