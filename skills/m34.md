# M34 · 數字爆裂計數 / Counter Burst

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with a dynamic, data-driven aesthetic, emphasizing precise numerical transitions and impactful, yet controlled, bursts of information. Focuses on `requestAnimationFrame` and `easeOutCubic` for all numerical animations.

---

### 字型系統
- **Display（計數、大型數字）**：Digital-7 Mono — 科技感數字，等寬
- **Mono（meta、時間軸、數據）**：Space Mono 400/700
- **Body（內文）**：Inter 300/400 + Noto Sans TC
- **Accent（標籤、次標）**：Rajdhani 500/700 — 帶有工程感的無襯線字

### 動態效果
1. **Counter Burst**：所有數字顯示都透過 `requestAnimationFrame` + `easeOutCubic` 從 0 爆裂計數到目標值，每次頁面載入或相關區塊進入視窗時觸發。
2. **Data Stream Background**：全屏 fixed overlay，以微弱的 `rgba(0, 229, 255, 0.05)` 矩陣點陣流動，模擬數據傳輸。
3. **Focus Highlight**：滑鼠hover時，相關卡片或互動元素邊框會從 `rgba(0, 229, 255, 0.2)` 瞬間閃爍並淡出。
4. **Section Entry Transition**：區塊進入 viewport 時，內容從下方淡入並向上輕微位移 (`transform: translateY(10px)`)。
5. **Progress Bar Animation**：時間軸或任務進度條使用 `width` 從 0 動態擴展。

### 構圖原則
- 深色背景為主，科技藍與故障紅為視覺焦點。
- 大量使用等寬字體和數字，強調數據感。
- 區塊邊界清晰，多用 1px `solid` 線條而非陰影。
- 資訊密度適中，留有負空間讓數字計數效果更突出。
- 元素對齊精確，強調工程與系統美學。

## 互動行為

- Topbar 時間與訪客數動態計數，每秒更新。

- Data Stream Background 持續緩慢流動。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer 版權年份計數到當前年份。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有 Counter Burst 計數動畫、Data Stream Background 及 Section Entry Transition，改為直接顯示最終值或靜態效果。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
