# C03 · Material You / Material 3

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page as a Material 3 surface — dynamic-color tonal palette derived from a seed, generous rounded shapes, elevation tiers expressed by tonal shift, expressive type scale, FAB-style call to action.

## 視覺語彙

### 色票（從 seed `#6750A4` 推導的 tonal palette）

```
--md-primary:           #6750a4
--md-primary-container: #eaddff
--md-on-primary:        #ffffff
--md-on-primary-container: #21005d

--md-secondary:         #625b71
--md-secondary-container: #e8def8

--md-tertiary:          #7d5260
--md-tertiary-container: #ffd8e4

--md-surface:           #fef7ff
--md-surface-dim:       #ded8e1
--md-surface-bright:    #fef7ff
--md-surface-container-low:  #f7f2fa
--md-surface-container:      #f3edf7
--md-surface-container-high: #ece6f0
--md-surface-container-highest: #e6e0e9

--md-on-surface:        #1d1b20
--md-on-surface-variant: #49454f
--md-outline:           #79747e
--md-outline-variant:   #cac4d0

--md-error:             #b3261e
```

整體採 **tonal elevation**：Surface 越「高」（layer 越上層）色調越亮、絕不用陰影區隔，全靠 tonal shift。

### 字型系統

- **Display（Hero、大型數字）**：Roboto Flex 400 / 700，opsz/wght 動態軸；中文用 Noto Sans TC 700
- **Headline**：Roboto Flex 500，letter-spacing 0
- **Body**：Roboto Flex 400 + Noto Sans TC 400，line-height 1.6
- **Label / Mono（FAB 文字、time）**：Roboto Flex 500 small caps
- **Numerals**：Roboto Flex tabular-nums

### 動態效果

1. **State layer**：所有可互動元件 hover/focus/pressed 時上方蓋一層 8-16% alpha 的 primary
2. **Ripple from pointer**：點擊處放射圓形 ripple、500ms ease-out + alpha fade
3. **FAB stretch**：scroll 到指定 anchor 時 FAB 從 icon-only 撐開成 extended（含 label）
4. **Container transform**：卡片 click 時 morph 成全頁 detail view（emulated）
5. **Tonal elevation transition**：卡片 hover 時 surface-container → surface-container-high 漸變、200ms
6. **Top app bar dock**：scroll 下移時 top bar 從 surface 變 surface-container（更亮）

### 構圖原則

- 圓角分級：button 20px / chip 8px / card 12px / large card 28px / FAB 16px（半徑要規範化）
- 沒有 box-shadow 區分層級，只用 surface container 色階
- 留白寬鬆：grid baseline 4dp、元件間距 8/16/24dp
- 強調 **expressive shapes**：不只圓角矩形，部分卡片可用 squircle、blob 變體（Material 3 expressive 主推）

## 文案 voice

Material 3 的策展論述要**友善 + 工程化**：
- 句子結構像 Google product blog post — 清楚、第二人稱、不裝高深
- 標題用 expressive Display style：「Twelve designers. One spectrum.」這類斷句
- 多用「動態 / 自適應 / 一致 / 個人化」這些 Material 哲學詞
- 中文不裝文學，務實直白：「這場展覽用十二個風格、回答一個問題」
- 副標可以用全英文 sentence case（不全大寫），與 c14 區隔
- 章節結尾用一個 FAB-style 行動指引：「了解更多 →」

## 互動行為

- 所有 button、card、chip hover 都掛 state layer（8% primary alpha）
- 點擊產生 ripple、從點擊點放射、500ms
- FAB 在 hero 區為 extended，scroll 下後縮回 icon-only，sticky 右下
- 卡片 hover surface-container → surface-container-high 漸變
- 票券 featured 卡使用 primary-container 區分（不靠 scale 或 shadow）
- PURCHASE 按鈕 `disabled aria-label="Demo only — not for sale"`

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 ripple、container transform、FAB stretch
- Material 3 tonal palette 設計時已驗證對比 ≥ AA，沿用即可
- 所有 icon button 需要 `aria-label`
- Focus ring 用 `--md-primary` 2px outline + 2px offset
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP
- Ripple 用 CSS pseudo-element 實作、不依賴 JS framework

## 衍生提示

C03 是 Google 系 / Android app 質感基底。延伸方向：
- 換 seed color（例 #006A6A 青綠）→ 全 palette 重新推導、變成另一個品牌
- 開 dark theme variant → 同樣 seed 但 surface 變 #1d1b20 起跳
- 強化 expressive shape（blob / squircle / asymmetric）→ 走 Material 3 expressive 2024+ 版

骨架不變、seed 換色 = 無限種 Material 變體。
