> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.

### 字型系統

- **Display（標題、Hero）**：VCR OSD Mono 或 Departure Mono — 退役 CRT 質感；fallback `Press Start 2P` for 像素感
- **Latin chrome**：Greek-style serif 或 Trajan — 大寫拉丁字配 Roman bust 美學
- **Japanese accent**：Noto Serif JP 細體 — vaporwave 必備片假名
- **Body（內文）**：Noto Sans TC 400，但字距特別寬（letter-spacing 0.15em）
- **Numerals**：mono、tabular

### 動態效果

1. **Sunset grid floor**：頁底固定一塊 CSS-only retro grid 地平線（perspective transform，cyan lines on purple）
2. **CRT scanlines**：全屏輕微 scanline overlay（比 c14 cyberpunk 更淡）
3. **Chrome 3D text**：標題用多層 text-shadow 模擬鉻金屬字（深紫→粉紅→白漸層）
4. **VHS chromatic aberration**：標題 hover 時 RGB split 200ms
5. **Static noise overlay**：fixed `radial-gradient` SVG noise 5% opacity
6. **Palm tree silhouette**：hero 兩側 CSS-shape 棕櫚樹剪影
7. **Sun setting**：hero 中央半圓「夕陽」用 conic-gradient 條紋（橘黃→粉紅→紫）

### 構圖原則

- 一切要「過量」：色彩飽和度拉到 100%、字距大、效果疊
- 構圖**對稱**：vaporwave 喜歡完美中央對稱（致敬蘇聯／古希臘）
- 大量「retro tech」物件：CRT、傳真機、撥號電話、棕櫚、希臘雕像
- 中央地平線、太陽、棕櫚 = 三大不可少
- 中英日三語混雜（中文主敘述 + Latin 大寫副標 + 片假名點綴）

## 文案 voice

蒸氣波的策展論述要**詩意 + 反諷 + 半夢遊**：
- 句子常用「殘響、回聲、失語、夢遊、未完成的未來」這類詞
- 中英日三語混雜：中文段落 + 拉丁大寫副標 + 片假名點綴
- 標題像 album title：「未完成的未來 / TOMORROW NEVER ARRIVED」
- 不寫實用 CTA、寫成詩句：「歡迎進入 1996 年從未發生的那個冬天」
- 引言可全大寫拉丁 + ALL CAPS 中文交錯
- 拒絕當代「行銷腔」、刻意製造 90 年代廣告文案質感

## 互動行為

- Sunset grid 地平線在頁底固定、scroll 不動
- 標題 hover 觸發 200ms RGB chromatic aberration
- LIVE 點閃爍 1.2s
- Scanline 全屏不隨滾動
- Marquee 在 footer 跑「アクアラックス・スペクトル ／ AQUALUX SPECTRUM ／ 設計光譜」三語循環 30s linear
- PURCHASE 按鈕 `disabled aria-label="Demo only — not for sale"`

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 chromatic aberration、scanline 動態、marquee
- 螢光高飽和色配色容易掉 a11y：白字 on 深紫底 OK，但粉紅字 on 紫底要校驗（必要時加 1px text-shadow 黑邊提升對比）
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP
- 過量 box-shadow / text-shadow 注意 paint 成本（限制在 hero 與 hover 觸發）

## 衍生提示

C06 是「90s mall × Roman ruins × CRT」的迷因合成基底。延伸方向：
- 抽掉 Roman bust、加強純棕櫚熱帶 → 走 Mallsoft / 海岸 vaporwave
- 換配色為冷藍灰 + 銀白 → Faux-corporate vaporwave（諷刺企業視覺）
- 加重像素感 → 走 Pixel vaporwave / 結合 Y2K（c07）

骨架不變、視覺記號重組 = 多種 retro 變體。
