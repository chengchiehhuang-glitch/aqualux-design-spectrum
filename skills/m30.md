# M30 · 滾動進度指示 / Scroll Progress

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with a clean, functional scroll progress aesthetic — a top progress bar and side-mounted chapter navigation dots. Focus on smooth, unobtrusive motion and clear informational hierarchy.

## 視覺語彙

### 色票
```css
--bg:          #ffffff   主背景（純白）
--paper:       #f9f9f9   內容區塊淺灰
--ink:         #1a1a1a   主字色
--ink-2:       #555555   次字色
--line:        #e0e0e0   分隔線/邊框色
--progress-bar-fill: #007bff   進度條填充色（藍）
--progress-bar-bg:   #e9ecef   進度條背景色
--chapter-dot-active: #007bff   章節點亮色
--chapter-dot-inactive: #cccccc   章節點暗色
```

### 字型系統
- **Display（標題、區段名稱）**：Inter 600/700 — 現代、清晰
- **Body（內文）**：Noto Sans TC 400 — 易讀、簡潔
- **Mono（meta、序號、時間）**：Fira Code 400 — 專業、程式感

### 動態效果
1. **頂部進度條**：使用 `scroll-driven-animations` 或 JavaScript 計算 `window.scrollY` 與 `document.body.offsetHeight`，動態更新 `width` 屬性。
2. **側邊章節點陣**：根據捲動位置，即時高亮當前章節對應的點。平滑的 `background-color` 過渡。
3. **區塊淡入**：當區塊進入視窗時，輕微的 `opacity` 和 `transform: translateY` 淡入效果。
4. **平滑捲動**：所有內部連結（如章節點擊）使用 `scroll-behavior: smooth`。
5. **hover 提示**：章節點 hover 時顯示清晰的章節名稱 tooltip。

### 構圖原則
- **極簡主義**：大量留白，內容為王。
- **清晰層次**：透過字體大小、粗細、顏色和留白明確區分資訊層次。
- **功能導向**：所有視覺元素都服務於導航和資訊呈現，避免冗餘裝飾。
- **固定元素**：頂部進度條和側邊章節點陣為 `position: fixed`，始終可見。
- **網格對齊**：內容區塊嚴格遵循網格系統，保持視覺一致性。

## 文案 voice

文案語氣應保持**專業、清晰、簡潔**的策展風格。強調資訊的組織與流暢性，避免過度修飾。
- 以**中性、客觀**的語氣介紹展覽和作品。
- 著重**邏輯性**與**結構性**的表達，如同設計本身。
- 用**精煉的詞句**描述設計理念和展區特色。
- 避免使用過於誇張或情緒化的詞彙。
- 策展論述可強調**「觀看」與「引導」**的關係，點出滾動進度指示的設計哲學。

## 互動行為

- 頂部進度條：隨著頁面捲動，藍色填充條從左至右增長，精確反映閱讀進度。
- 側邊章節點陣：
    - 點擊任一點可平滑捲動至對應章節。
    - 捲動時，當前章節的點會亮起（變為 `--chapter-dot-active` 色）。
    - Hover 時顯示章節名稱的簡潔 tooltip。
- 區塊淡入：當各區段（如策展論述、設計師名單）首次進入視窗時，會有一個輕微的 `opacity` 和 `translateY` 動畫，優雅地呈現內容。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。

---

## a11y / 性能

- `<main>` landmark 包所有主內容，提供清晰的導航結構。
- `prefers-reduced-motion: reduce`：禁用區塊淡入效果，進度條和章節點的過渡動畫改為瞬時變化。
- 章節點導航使用 `<nav>` 和 `<a>` 標籤，並提供 `aria-label`。
- 圖片全部 `loading="lazy" decoding="async"`，優化載入性能。
- 全 PNG 轉 WebP（~91% 大小縮減），減少檔案大小。
- 確保所有文字對比度符合 WCAG 標準。
- 進度條使用 `aria-valuemin`, `aria-valuemax`, `aria-valuenow` 確保輔助技術可讀取進度。
