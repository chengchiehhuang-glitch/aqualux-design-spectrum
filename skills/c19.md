### 字型系統
- **Display（標題、Z01 巨型字）**：Noto Serif SC 900 / FZShuSong-Z01S — 宋體 / 仿宋體，筆畫剛勁有力
- **Mono（meta、印章、時間軸）**：Source Han Serif SC 400 / FZKai-Z03S — 楷體 / 隸書風格，用於點綴
- **Body（內文）**：Noto Sans SC + Microsoft YaHei
- **Calligraphic accent**：FZShuSong-Z01S — 用於印章、局部題字

### 動態效果
1. **水墨暈染**：背景 fixed overlay、`radial-gradient` 模擬水墨擴散、`mix-blend-mode: multiply` 或 `overlay`
2. **描金邊框**：元素 `::before` `::after` 偽元素 + `linear-gradient` 模擬金屬光澤、`transform: scale(1.02)` 輕微呼吸效果
3. **雲紋背景**：SVG 雲紋圖案、`background-repeat: repeat`、`animation: scrollCloud 60s linear infinite` 慢速移動
4. **印章浮現**：特定區塊（如策展人簽名）`opacity: 0` 初始，`transition: opacity 1s ease-in` 滾動到視窗時浮現
5. **竹影搖曳**：`filter: drop-shadow` 模擬竹影，`@keyframes sway 8s ease-in-out infinite` 輕微擺動

### 構圖原則
- 留白為主、墨黑與硃紅為點綴
- 字體磅礴、筆畫清晰（行距 1.5-1.8em）
- 邊框以水墨、描金或雲紋勾勒
- 區塊分隔用書法線條、印章、或傳統窗格元素

## 文案 voice

國潮風格的策展論述要**結合古典詩意與當代語境** + **東方哲思**：
- 不只敘述功能，更要傳達一種意境（「此展覽旨在⋯」）
- 強調東方美學的包容與創新（「傳統與現代並非對立，而是相生相伴的兩股氣韻」）
- 引用古籍、詩詞典故，或仿古文言文句式
- 結合現代潮流術語，創造新舊對話感
- 中文為主，英文為輔，英文標題可採用較為古典的詞彙

## 互動行為

- Topbar 祥雲圖標緩慢飄動 1.2s
- Hero 標題描金邊框每 3s 輕微呼吸一次
- 水墨暈染背景 5 個 `radial-gradient` 慢速擴散（28s loop）
- 雲紋背景 `scrollCloud` 動畫不隨滾動
- PURCHASE 按鈕現為 `disabled aria-label="展示品 — 不開放購買"`
- Footer 落款印章 `opacity` 緩慢浮現 0.9s

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用水墨暈染 / 描金邊框 / 雲紋背景
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
