### 色票
```
--bg:        #f0f0f0   主淺灰底
--paper-sub: #ffffff   卡片底
--accent-primary: #3b82f6   主強調（活潑藍）

--text-dark: #1f2937   深色文字
--text-medium: #4b5563   中度文字
--text-light: #9ca3af   淺色文字
--border-light: #e5e7eb   淺邊線
```

### 字型系統
- **Display（標題、巨型字）**：Inter 700/900 — 現代、清晰，適合動態展示
- **Body（內文、卡片資訊）**：Source Sans Pro 300/400 — 高可讀性，襯托動態效果
- **Mono（時間軸、編號）**：Roboto Mono 300/500 — 精確、科技感

### 動態效果
1. **主滾動轉換**：`window.scrollY` 映射為 `transform: translateX()`，實現全頁橫向滾動。
2. **視差背景**：多層背景元素以不同 `transform: translateZ()` 或 `transform: scale()` 速度橫向移動，創造深度。
3. **Sticky 元素**：關鍵文字區塊 `position: sticky` 配合 `transform: translateX()` 保持在視窗內，直到內容滾動完畢。
4. **卡片滑入**：橫向滾動時，卡片元素從側邊 `opacity: 0` `transform: translateX(50px)` 漸入。
5. **進度條**：頂部固定進度條，隨橫向滾動進度更新寬度。

### 構圖原則
- **內容分區**：每個「區段」是一個完整的水平面板，透過橫向滾動切換。
- **留白策略**：利用大量留白引導視線，突顯動態效果和核心內容。
- **對齊與網格**：內容元素嚴格遵循網格系統，確保在動態中依然保持秩序。
- **層次疊加**：利用 `z-index` 和 `transform: translateZ()` 創造景深，多層元素同時橫向移動。

## 文案 voice

橫向滾動的策展論述要**強調流程、連結性與沉浸感**：
- 不要靜態敘述（「這個展覽展示了...」）
- 要動態引導（「從一個概念流淌到下一個實踐，我們邀請你沉浸在這場流動的體驗中」）
- 用動詞 + 進行式，強調過程與轉換
- 強調「流動」、「路徑」、「旅程」等關鍵字
- 英文副標強調動態與交互

---

## 互動行為

- 整個頁面垂直滾動條被禁用，僅響應 `wheel` 事件或手勢觸發橫向滾動。
- Hero 區的引導箭頭會輕微脈動，提示使用者滾動。
- 設計師卡片在橫向滾動時，會從透明逐漸顯現並放大。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- 頁腳固定在右下角，不隨橫向滾動改變位置。

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用所有視差、卡片滑入等複雜動畫，僅保留基礎橫向滾動。
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
- 使用 CSS `will-change: transform` 預優化滾動相關的動畫性能。
