# C05 · 沉浸暗黑 / Immersive Dark

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in modern dark-mode aesthetic — true-black canvas, surface tiers built by elevation grey, a single bright accent for emphasis, content that breathes in the void. Think Linear app × Vercel dashboard × Apple TV.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 c05 沉浸暗黑版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 20 張 gpt-image-2 生圖。整套素材 ~28 KB HTML + ~3 MB WebP（轉檔後）。

## 視覺語彙

### 色票

```
--bg:           #0a0a0b   真黑主底（非純黑、略帶藍）
--surface-1:    #111114   卡片底（elevation 1）
--surface-2:    #18181c   懸浮層（elevation 2）
--surface-3:    #1f1f24   modal / overlay
--surface-4:    #2a2a30   hover 強調
--border:       #26262c   髮絲邊界
--border-hi:    #3a3a42   強調邊界
--ink:          #f5f5f7   主字（不純白、減少疲勞）
--ink-2:        #a8a8b0   次字
--ink-3:        #6b6b73   弱字（meta、caption）
--ink-4:        #45454d   極弱字（disabled）
--accent:       #4cd2c4   薄荷青 accent（單色 accent）
--accent-soft:  rgba(76,210,196,0.12)
--accent-hi:    #8af5e8   accent 高亮
--shadow-deep:  0 24px 64px rgba(0,0,0,0.6)
```

關鍵原則：**所有 surface 都不是同樣的黑**，靠 elevation 色階建立層級；不依賴白色邊框、不用花俏漸層。

### 字型系統

- **Display（標題、Hero）**：Inter Tight 600/700，letter-spacing -0.025em — 緊湊現代
- **Mono（meta、coord、票券序號、code）**：JetBrains Mono 400
- **Body（內文）**：Inter 400 + Noto Sans TC 400，line-height 1.65
- **Numerals**：Inter tabular-nums

### 動態效果

1. **Spotlight cursor**：滑鼠 hover 在卡片上時、卡片背景以游標為中心出現 radial-gradient 微亮（typical Linear / Vercel cards）
2. **Subtle glow on accent**：accent 元件邊緣 `box-shadow: 0 0 24px rgba(76,210,196,0.18)`
3. **Smooth scroll reveal**：section 進入 viewport 時 fade-up 16px、420ms ease-out
4. **Surface elevation on hover**：surface-1 → surface-2 切換、220ms
5. **Cursor blink**：terminal-style cursor 出現在 CTA 文字後
6. **Marquee**：footer 或 partner row 可加慢速橫向滾動 logo strip（24s linear loop）
7. **Hairline divider with edge fade**：分隔線左右 8% 透明度漸入漸出

### 構圖原則

- 大量負空間、留白比主流 UI 多 1.5 倍（hero padding 160px+）
- 圓角適中：6-10px（不像 Material 的 28px、不像 Brutalism 的 0）
- 邊框 1px solid `--border`，搭配 surface 階層
- accent 用得**極省**：一頁最多 3 處 accent 元件（CTA、active link、key number）
- 內容靠 hierarchy 區分而非裝飾：字級、字色、間距

## 文案 voice

沉浸暗黑的策展論述要**克制 + 高自信**：
- 句子短、句點多、不堆形容詞
- 一個段落只講一件事
- 標題用斷句法：「Twelve designers. One spectrum. Sixteen days.」
- 中文用「沉、深、靜、廣、留」這類字
- 不用感嘆號、不用「最 / 超 / 極」這類副詞放大
- 引言可像產品 launch tagline：「Design, in its true tones.」
- Operator 模式比例提高（70%）— 直接陳述「我們做了什麼」、不繞圈

## 互動行為

- 卡片 hover：surface-1 → surface-2 + spotlight cursor radial-gradient
- accent CTA hover：box-shadow glow 擴張 + scale 1.02
- Section reveal：IntersectionObserver fade-up 420ms
- Terminal cursor `_` 閃爍 0.9s 在 hero CTA 文字尾
- Footer marquee 24s linear loop（hover 暫停）
- PURCHASE 按鈕 `disabled aria-label="Demo only — not for sale"`

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 spotlight cursor、marquee、fade-up
- 暗黑模式對比要嚴格：`--ink` on `--bg` ≥ 14:1（AAA），accent on dark ≥ 4.5:1
- **不可在純黑底用純白字**：用 `#f5f5f7` 不用 `#ffffff` 減少視覺振動
- Focus ring：2px solid `--accent` + 2px offset、永遠可見
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP
- Spotlight cursor 用 CSS variable 跟 JS pointer 連動、節流到 60fps

## 衍生提示

C05 是「modern SaaS / dev tool」家族基底。延伸方向：
- accent 換色（藍 / 紫 / 橘） → 不同品牌的暗黑變體
- 加入更多 mono 元素 → 更靠近 dev tool / docs site
- 結合 c01 玻璃 → dark glass 變體（半透明深色玻璃）
- 結合 c14 賽博龐克 → 加 neon 但保持克制 = high-end gaming UI

骨架不變、accent 單色換 = 一票暗黑變體。
