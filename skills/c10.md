### 字型系統
- **Display（標題、Z01 巨型字）**：'Press Start 2P', 'VT323' — 像素感、復古電玩
- **Mono（meta、終端機、時間軸）**：'Roboto Mono' 300/700 — 數位科技感
- **Body（內文）**：Noto Sans TC + PingFang TC — 可讀性
- **Accent**：'Righteous', 'Bebas Neue' — 粗獷、復古海報字體

### 動態效果
1. **Perspective Grid**：全屏 `::before` 偽元素，`linear-gradient` 模擬透視網格，`background-size` 配合 `animation` 緩慢移動，創造無限延伸感。
2. **Neon Glow**：關鍵文字和按鈕 `text-shadow` 或 `box-shadow` 多層疊加，模擬霓虹燈發光效果，顏色為 `--neon-purple` 或 `--neon-pink`。
3. **Retro Scanlines**：輕微透明的 `repeating-linear-gradient` 覆蓋層，模擬 CRT 螢幕紋理，`mix-blend-mode: overlay`。
4. **Sunset Gradient**：背景 `linear-gradient` 緩慢從深紫 `to` 亮粉 `to` 淺藍漸變，模擬 Synthwave 標誌性落日。
5. **VHS Glitch**：局部元素（如圖片 hover）`filter: blur()` 和 `transform: translateX()` 短暫抖動，模擬 VHS 錄影帶失真。

### 構圖原則
- 深色背景為主，霓虹色塊和線條為點綴，避免過度飽和。
- 大量使用水平和垂直的幾何線條，形成方正、透視感強烈的區塊。
- 善用漸層（特別是紫、粉、藍、洋紅漸層）來定義空間和元素。
- 元素邊緣銳利，少圓角，強調數位和機械感。
- 運用對稱構圖和中心透視來引導視線。

## 文案 voice

以 80s Synthwave 語氣包裝策展論述，強調懷舊、未來感、數位詩意：
- 語氣帶點復古的「酷」與「神秘」，避免過度學術。
- 運用 80 年代流行語或風格化表達。
- 強調「光譜」在數位與懷舊之間的連結。
- 副標題可使用 ALL CAPS，字型帶有數位感。
- 避免過於口語，保持策展的專業度。

## 互動行為

- Topbar `LIVE` 點閃爍，像素風格。
- Hero 霓虹標題 `text-shadow` 緩慢脈動，模擬霓虹燈開關。
- Perspective Grid 背景緩慢、無限延伸的動畫。
- Sunset Gradient 背景 28s loop 的顏色緩慢漸變。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。
- Footer terminal cursor `_` 閃爍 0.9s。
- 圖片 hover 時，觸發輕微的 VHS Glitch 效果。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有背景動畫、霓虹脈動、VHS glitch。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
