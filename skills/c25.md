### 字型系統
- **Display（標題、Z01 巨型字）**：Montserrat 400/700 — 現代、圓潤的流動感
- **Mono（meta、終端機、時間軸）**：Fira Code 300/500 — 精確、輕盈
- **Body（內文）**：Noto Sans TC + PingFang TC
- **Japanese accent**：Noto Sans JP — 用片假名做次標、設計師名

### 動態效果
1. **Liquid Background**：全屏 `background-blend-mode: overlay` 的多層 `radial-gradient`，以 `transform: translate()` 緩慢、流動地移動，形成液態極光效果（28s loop）。
2. **Soft Glow Elements**：卡片邊緣及重要文字使用 `text-shadow` 或 `box-shadow` 搭配 `filter: blur()` 產生柔和光暈。
3. **Pulsating Spheres**：背景中數個半透明 `div` 元素，應用 `background: radial-gradient` 模擬柔光球體，以 `opacity` 及 `transform: scale()` 進行緩慢脈動（5s 循環）。
4. **Subtle Mesh Lines**：背景疊加一層極細微、半透明的 `linear-gradient` 網格線，僅在特定光照角度下可見。
5. **Ethereal Hover**：互動元素 `hover` 時，背景色塊以 `transition` 緩慢變色並擴散柔和光暈。

### 構圖原則
- 深色背景為主，利用大面積漸層色塊營造空間感。
- 元素邊緣柔和，避免銳利直線與直角。
- 字體輕盈、間距適中，與流動感背景形成對比。
- 資訊分層清晰，但透過色彩與光暈而非硬性邊界區分。
- 運用球體、波浪或有機形狀作為裝飾性元素。

## 文案 voice

漸層 Mesh 的策展論述要**探索無形之美** + **流動的哲學**：
- 不要僵硬的定義，要詩意的描述流動與變幻
- 要結構性對立（「硬邊幾何與流動漸層不只呈現不同視覺，更反映兩種對現實的感知」）
- 用 > 柔和光暈引言、ALL CAPS 副標
- 中英夾雜（中文主敘述 + 英文 ALL CAPS 副標）
- 片假名做次標

## 互動行為

- Topbar `LIVE` 柔光點閃爍 1.2s
- Hero 標題柔和光暈，每 3s 緩慢擴散與收縮一次
- Liquid Background 緩慢流動（28s loop）
- Subtle Mesh Lines fixed overlay 不隨滾動
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer terminal cursor `_` 閃爍 0.9s

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 liquid background / pulsating spheres
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
