# C12 · 野獸派 / Brutalism

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in full brutalist aesthetic — raw concrete, harsh typography, exposed structure, and aggressive contrast.

---

## 用法（給 Claude Code 使用者）

把這份 SKILL.md 丟給 Claude Code、加一句「依此 spec 生成 c12 野獸派版的 aqualux 2026 設計光譜展單檔網頁」，會產出 `index.html` + 20 張 gpt-image-2 生圖。整套素材 ~30 KB HTML + ~3 MB WebP（轉檔後）。

## 視覺語彙

### 色票
```
--concrete:    #4a4a4a   主深灰（裸露混凝土）
--concrete-lt: #8a8a8a   次淺灰
--steel:       #c0c0c0   金屬質感
--warning:     #ff0000   警示紅（高對比）
--ink:         #ffffff   文字白
--ink-secondary: #e0e0e0 次要文字
--bg-panel:    #2a2a2a   深色區塊背景
```

### 字型系統
- **Display（標題、Z01 巨型字）**：Impact (fallback: Arial Black) — 粗獷、無襯線、高辨識度
- **Mono（meta、終端機、時間軸）**：IBM Plex Mono 400/700 — 技術感、結構化
- **Body（內文）**：Noto Sans TC + PingFang TC — 簡潔、易讀
- **Accent**：Staatliches — 極端粗獷、大寫專用

### 動態效果
1. **Structural Grid**：全屏 fixed overlay、`linear-gradient` 1px 鋼灰色線、45度角交錯、mix-blend-mode: overlay
2. **Text Glitch**：重要標題 `::before` `::after` 偽元素 + `clip-path` + 隨機 `transform` 偏移、0.2s 循環、模擬破損
3. **Flicker Border**：區塊邊框 `box-shadow` 隨機閃爍 0.1s、模擬老舊螢幕或電路不穩
4. **Heavy Scroll**：`scroll-behavior: smooth` 禁用，模擬粗暴直接的互動
5. **Cursor Blink**：`@keyframes blink 0.7s steps(1) infinite` 模擬終端機游標

### 構圖原則
- 裸露結構為主、大量留白（或留灰）為輔
- 字體特大、字距特寬（letter-spacing 0.1em-0.2em）
- 框線極粗、用色塊和強對比做分隔
- 資訊堆疊、缺乏層次，模擬「資料牆」
- 刻意反 UX，強調功能性而非美觀性

## 文案 voice

野獸派的策展論述要**反對過度美化** + **強調本質**：
- 不要中性敘述（「這個展覽 explores...」）
- 要結構性對立（「極簡主義追求純粹，野獸派則揭示真相 — 兩種對真實的極端詮釋」）
- 用 > 終端機式引言、ALL CAPS 副標
- 中英夾雜（中文主敘述 + 英文 ALL CAPS 副標）
- 片假名做次標

## 互動行為

- Topbar `WARNING` 點閃爍 0.7s
- Hero glitch 標題 RGB 偏移每 0.5s 隨機抖動一次
- Structural Grid 靜態，不隨滾動
- Flicker Border 區塊邊框每 0.1s 隨機閃爍
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer terminal cursor `_` 閃爍 0.7s

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用 glitch / flicker / structural grid
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
