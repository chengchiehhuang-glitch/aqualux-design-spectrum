# M37 · 動態噪點 / Noise Grain

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page with a living, breathing noise grain aesthetic — subtle filmic textures, organic color shifts, and a sense of constant, gentle motion.

## 視覺語彙

### 色票
```
--bg-primary:    #1a1a1a   主背景，深灰近黑
--bg-secondary:  #2f2f2f   次背景，用於區塊或卡片
--ink-light:     #e0e0e0   淺色文字，高對比
--ink-medium:    #b0b0b0   中性文字，內文
--ink-dark:      #808080   弱化文字，meta資訊
--accent-warm:   #f0a500   暖調強調色
--accent-cool:   #00a8cc   冷調強調色
--grain-overlay: rgba(0,0,0,0.08)  噪點疊加層，微透明黑
```

### 字型系統
- **Display（標題、巨型字）**：Inter 700/900 — 現代、清晰，但透過噪點處理賦予質感
- **Body（內文）**：Noto Sans TC + system-ui — 易讀，與噪點背景形成對比
- **Mono（meta、時間軸）**：IBM Plex Mono 300/500 — 營造數據感與精準度
- **Japanese accent**：Noto Sans JP — 用片假名做次標、設計師名

### 動態效果
1. **Noise Grain Overlay**：全屏 fixed overlay，SVG `<feTurbulence>` filter 配合 `hue-rotate` 和 `saturate`，`animation` 讓 `baseFrequency` 和 `seed` 緩慢變動。
2. **Subtle Hue Shift**：全局 `filter: hue-rotate()` 緩慢循環，營造有機色彩浮動感。
3. **Soft Pulse Highlight**：卡片或互動元素 hover 時，背景 `box-shadow` 輕微發散，配合 `filter: brightness(1.1)` 提升亮度。
4. **Text Jitter**：部分標題文字，透過 `transform: translate()` 配合 `calc(random() * 0.5px)` 產生微小、不規則的像素位移，模擬舊式螢幕顯示。
5. **Flicker Cursor**：輸入框或互動游標，`@keyframes flicker 0.6s steps(1) infinite` 模擬老舊 CRT 顯示器。

### 構圖原則
- 深色背景為主，營造沉浸感。
- 資訊區塊間留有足夠的呼吸空間，避免視覺混亂。
- 使用柔和的區塊分隔，而非硬邊框，讓噪點能自然過渡。
- 強調與背景有層次對比，但不過於突兀，維持整體柔和感。
- 避免純色大塊面積，所有區塊都應有噪點濾鏡或半透明疊加。

## 文案 voice

以 Operator 視角，探討 Noise Grain 在數位時代的「真實性」與「缺陷美學」。語氣沉穩，帶有實驗精神：
- 強調「缺陷即美學」、「數位原生紋理」而非「雜訊」。
- 用 > 終端機式引言、ALL CAPS 副標。
- 中英夾雜（中文主敘述 + 英文 ALL CAPS 副標）。
- 片假名做次標。
- 避免過度浪漫化，保持技術與美學的平衡。

## 互動行為

- Topbar `LIVE` 點閃爍，帶有輕微的噪點模糊效果。
- Hero 標題文字持續有微小、隨機的像素抖動，模擬舊式顯示器的不穩定感。
- 全局 SVG turbulence filter 緩慢、有機地變化 `baseFrequency` 和 `seed` 屬性（28s loop）。
- 局部互動元素（按鈕、卡片）hover 時，背景產生柔和的噪點擴散光暈。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。
- Footer terminal cursor `_` 閃爍，帶有輕微的噪點邊緣。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有噪點動畫、色彩偏移和文字抖動，僅保留靜態噪點紋理。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- SVG filter 應優化，避免過度複雜的計算導致性能問題。
