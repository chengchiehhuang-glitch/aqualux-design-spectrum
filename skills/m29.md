## 視覺語彙

### 色票
```
--bg:          #fdfdfd   主背景（近白）
--paper:       #ffffff   內容區塊（純白）
--ink:         #1a1a1a   主字色（深灰）
--ink-2:       #595959   次字色（中灰）
--divider:     #e0e0e0   章節分隔線
--accent:      #007bff   強調色（品牌藍）
--accent-light:#eaf6ff   輕強調（背景）
--shadow-light:rgba(0,0,0,0.05) 輕微陰影
```

### 字型系統
- **Display（章節標題）**：Inter Variable Font 700/800 — 現代、清晰
- **Body（內文）**：Noto Sans TC 400/500 + Inter 400/500
- **Mono（meta、序號）**：JetBrains Mono 300/400

### 動態效果
1. **Scroll Snap**：`scroll-snap-type: y mandatory;` + `scroll-snap-align: start;` 確保每個章節精準對齊，提供平滑、分段的滾動體驗。
2. **Sticky Navigation**：頂部導航列 `position: sticky; top: 0;` 保持可見，並隨滾動自動更新當前章節指示。
3. **Fade-in Elements**：新進入視窗的內容元素（如圖片、卡片）使用 `opacity: 0; transition: opacity 0.5s ease-out;` 搭配 Intersection Observer 逐漸淡入。
4. **Subtle Scale on Hover**：互動元素（如卡片、按鈕）`transform: scale(1.02); transition: transform 0.2s ease-out;` 提供輕微回饋。

### 構圖原則
- **全屏章節**：每個主要內容區塊佔據整個視窗高度，視覺上清晰區分。
- **大量留白**：每個章節內部保持充裕的留白，減少視覺壓迫感。
- **居中對齊**：章節標題和核心內容傾向於居中對齊或清晰的網格佈局。
- **極簡線條**：使用細緻的 `1px solid --divider` 作為章節或內容區塊的視覺分隔，避免厚重邊框。
- **清晰層次**：透過字重、字體大小和顏色差異來建立內容層次，而非複雜的背景或裝飾。

## 文案 voice

文案風格應與品牌「無印 × 顧問 × Operator」精神一致，體現清晰、有結構的策展視角：
- **精準敘述**：避免口語化，使用專業且簡潔的語言。
- **結構化洞察**：將設計流派或作品的「核心洞見」清晰呈現。
- **策展人視角**：以「我們策劃」、「我們觀察到」等角度引導讀者。
- **強調體驗**：文案中融入對 Scroll Snap Acts 滾動體驗的描述，如「分段式探索」、「沉浸式體驗」。
- **中英並陳**：主要內容為中文，但重要術語或副標可輔以英文。

## 互動行為

- 頁面主體 `scroll-snap-type: y mandatory;`，每個章節（`section` 或 `div`）設置 `scroll-snap-align: start;`。
- Topbar 導航連結點擊後，使用 `scroll-into-view({ behavior: 'smooth', block: 'start' });` 平滑滾動到對應章節。
- Topbar 導航會根據當前可見的 Scroll Snap 章節自動高亮。
- 購票按鈕 `PURCHASE` 預設為 `disabled aria-label="Demo only — not for sale"`。

---

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有滾動動畫和淡入效果，僅保留 Scroll Snap 功能本身。
- `aria-label` 和 `role` 確保導航和互動元素的語義化。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- 使用 `will-change: scroll-position` 針對滾動性能優化。
- 確保所有文本具備足夠的對比度。
