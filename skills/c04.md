## 視覺語彙

### 色票
```
--bg:        #ffffff   主背景（純白）
--paper:     #fafaf5   紙色（卡片、內容區塊）
--ink:       #1a1a1a   主字（深灰而非純黑）
--ink-2:     #4a4a4a   次字（內文）
--ink-3:     #8a8a8a   弱字（meta、註解）
--accent:    #5c7a9a   柔灰藍（連結、重點）
--line:      #e8e6e0   分隔線（細緻）
--line-soft: #f0eee8   弱分隔線（卡片邊）
```

### 字型系統
- **Display（標題、巨型字）**：Noto Serif TC 300/400 — 沉穩、有筆鋒的優雅
- **Mono（meta、編號、時間軸）**：JetBrains Mono 300/700 — 簡潔、具功能性
- **Body（內文）**：Noto Sans TC 400 + PingFang TC — 清晰、易讀
- **Accent/Numbers**：Cormorant Garamond italic — 用於章節編號、年份等裝飾性元素

### 動態效果
1. **淡入漸顯**：所有內容區塊預設 `opacity: 0`，viewport 進入時 `transition: opacity 0.8s ease-out` 漸顯。
2. **微光標示**：懸停在互動元素上時，背景 `box-shadow: inset 0 0 0 1px var(--accent-soft)` 微光邊框。
3. **頁面切換**：模擬翻頁效果，`transform: translateX(-100%)` 或 `clip-path` 慢速切換。
4. **游標互動**：自定義游標為一個小圓點，hover 時變大或變色。
5. **文字排版**：標題文字 `letter-spacing: 0.05em`，製造呼吸感。

### 構圖原則
- **大量留白**：頁面元素間距寬闊，營造寧靜、呼吸的空間。
- **單色字體**：主要使用 `--ink` 色系，不依賴色彩區分層級。
- **編輯級排版**：嚴謹的網格系統，對齊、縮排、行距精準控制。
- **無邊框無陰影**：物件之間主要透過留白與細線分隔，不使用圓角或立體效果。
- **資訊層次**：透過字重、字級、線條粗細來表達資訊層級，而非顏色。

## 文案 voice

極簡主義的策展論述要**精煉** + **結構化** + **本質洞察**：
- 避免冗詞贅句，每個字都承載意義。
- 透過留白與排版強化閱讀體驗。
- 強調設計的「核心」、「本質」、「功能」。
- 用簡潔的中文敘述，搭配英文作為輔助標題。
- 避免口語化、情緒化表達。

---

## 互動行為

- 內容區塊 `opacity: 0` 初始值，滾動進入 viewport 時 `opacity: 1` 漸顯。
- 導航連結 hover 時，文字顏色 `transition: color 0.3s ease-out` 變為 `--accent`。
- 按鈕 hover 時，背景 `box-shadow: inset 0 0 0 1px var(--accent)`，無背景色變化。
- 圖片點擊時，以 `opacity: 0.8` 輕微變暗，表示互動。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。

---

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有漸顯、轉場動畫，直接顯示內容。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- 使用語義化 HTML 結構，確保輔助技術能正確解析。
