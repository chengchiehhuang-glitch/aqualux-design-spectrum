# C16 · ASCII 終端機 / ASCII Terminal

> Single-file HTML demo skill for the aqualux 2026 設計光譜展 codex.
> Renders the fictional exhibition page in full ASCII Terminal aesthetic — green phosphor, monospace fonts, ASCII art, and a classic 80x24 grid.

## 視覺語彙

### 色票
```
--bg:        #000000;   主黑底
--phosphor:  #00ff00;   綠螢光主色
--phosphor-dim: #008800; 次螢光（弱化）
--text-main: #00ff00;   主要文字色
--text-dim:  #00aa00;   次要文字色
--grid-line: #003300;   網格線色
--error-red: #ff0000;   錯誤/警示紅
--blink:     #00ff00;   游標閃爍色
```

### 字型系統
- **Display（標題、Z01 巨型字）**：VT323 或 Fira Code (with ligatures for ASCII art) — 經典終端機字體，強調等寬
- **Mono（meta、終端機、時間軸）**：IBM Plex Mono 或 DejaVu Sans Mono — 確保等寬字符對齊
- **Body（內文）**：IBM Plex Mono 或 DejaVu Sans Mono — 全文等寬，模擬終端機顯示
- **Japanese accent**：Noto Sans JP Mono — 等寬片假名，用於次標、設計師名

### 動態效果
1. **螢幕掃描線 (Scanlines)**：全屏 fixed overlay，`repeating-linear-gradient` 1px 黑紋，`mix-blend-mode: overlay`，模擬 CRT 效果。
2. **文字綠輝 (Phosphor Glow)**：所有主要綠色文字應用 `text-shadow: 0 0 1px var(--phosphor), 0 0 2px var(--phosphor);`。
3. **終端機游標閃爍 (Blink Cursor)**：`@keyframes blink 0.8s steps(1) infinite;` 應用於模擬游標 `_`，`background-color: var(--blink);`。
4. **文字輸入效果 (Typewriter Effect)**：部分標題或關鍵信息，字元逐一顯示，配合閃爍游標。
5. **故障抖動 (Glitch Jitter)**：少部分強調文字，通過 `transform: translateX(random_value) translateY(random_value);` 配合 `text-shadow` 產生輕微抖動。

### 構圖原則
- 80x24 字元網格模擬：所有內容應感覺被限制在終端機的固定網格內。
- 純文字 ASCII Art：大量使用 `_ / \ | - = # [] <>` 等字元構成圖形、分隔線、標題裝飾。
- 嚴格等寬字體：所有文字必須使用等寬字體，確保排版對齊。
- 綠底黑字或黑底綠字：經典 phosphor 顯示器配色。
- 無圖形、無圓角、無陰影：純粹的文字與符號構成。
- 區塊分隔用 ASCII 線條或空行。

## 文案 voice

終端機風格的策展論述要**指令式** + **系統日誌** + **數據流**：
- 不用傳統語法，改用 `>` 或 `$` 開頭的指令提示符。
- 內文模擬日誌輸出，加入 `[OK]`, `[ERROR]`, `[WARNING]` 等狀態標籤。
- 強調「處理 (PROCESS)」、「分析 (ANALYZE)」、「執行 (EXECUTE)」等動詞。
- 大量使用 ALL CAPS 副標，模擬程式碼或系統訊息。
- 中英夾雜，中文為主體，英文 ALL CAPS 作為系統指令或關鍵字。
- 片假名用等寬字體，作為系統標籤或資料欄位。

## 互動行為

- Topbar `LIVE_STREAM_ACTIVE` 狀態文字閃爍 1.2s。
- 游標 `_` 在所有輸入框或可交互元素旁閃爍 0.8s。
- 標題文字可加入模擬打字機效果，逐字顯示。
- `PURCHASE` 按鈕現為 `[DISABLED] - Access Denied (Demo Only)`。
- Footer terminal prompt `>` 後的游標閃爍 0.9s。
- 點擊可互動元素時，會顯示簡短的 `[PROCESSING...]` 或 `[EXECUTING...]` 字樣。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有閃爍、打字機效果與抖動。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- 所有文字使用等寬字體，確保排版可預測性。
- 高對比度配色（綠 on 黑），確保可讀性。
