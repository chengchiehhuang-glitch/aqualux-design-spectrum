> Renders the fictional exhibition page in full Scandinavian aesthetic — warm wood, clean sans-serifs, muted tones, and subtle illustrations.

## 用法（給 Claude Code 使用者）

### 字型系統
- **Display（標題、Z01 巨型字）**：Montserrat 500/700 — 清爽現代，具設計感
- **Body（內文）**：Noto Sans TC + PingFang TC — 易讀性高，簡約
- **Accent（次標、meta、年份）**：Lato 300/400 — 柔和，與 Noto Sans TC 協調
- **Illustrative accent**：手寫字體（如: Caveat Brush）— 用於插畫 caption 或特殊強調

### 動態效果
1. **柔和淡入**：所有區塊或圖片載入時，`opacity: 0` 至 `1`，`transition: opacity 0.8s ease-out`。
2. **hover 抬升**：卡片 `box-shadow` 輕微抬升 `0 4px 12px rgba(0,0,0,0.08)`，`transform: translateY(-4px)`，`transition: all 0.3s ease-in-out`。
3. **背景紋理**：全屏 `fixed overlay`，輕微 `noise.png` 紋理，`mix-blend-mode: multiply`, `opacity: 0.03`。
4. **木質細節**：部分區塊（如 footer 或特定分隔線）使用 `linear-gradient` 模擬淺色木紋，或直接嵌入 `wood-texture.webp`。
5. **Icon 動畫**：小型 icon (如導覽列) hover 時，`transform: scale(1.1)`，`transition: transform 0.2s ease-out`。

### 構圖原則
- 大量留白、負空間為主、營造輕盈感
- 簡潔的線條、有機形狀的運用
- 元素對齊、網格系統、保持秩序感
- 柔和的邊緣、避免銳利對比
- 少量且精緻的插畫作為點綴

## 文案 voice

北歐極簡的策展論述要**溫和而深刻** + **重視本質**：
- 避免浮誇詞藻，用詞簡潔而精準
- 強調設計的「功能」、「永續」、「人本」
- 用自然、溫暖、真實的語氣
- 少量英文搭配中文，英文用於副標或強調核心概念

## 互動行為

- Topbar Logo 輕微 `transform: scale(1.02)` on hover
- Hero 標題文字在載入時，每個字元依序淡入 `animation-delay`
- 背景紋理固定不隨滾動
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`
- Footer 年份 `MMXXVI` 輕微淡入

---

## a11y / 性能

- `<main>` landmark 包所有主內容
- `prefers-reduced-motion: reduce` 停用所有淡入、抬升動畫
- Table `<th scope="col">` 標欄
- 圖片全部 `loading="lazy" decoding="async"`
- 全 PNG 轉 WebP（~91% 大小縮減）
