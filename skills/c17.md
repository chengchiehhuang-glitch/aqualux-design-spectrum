## 視覺語彙

### 色票
```
--bg:        #fcfaf6   主紙白
--paper:     #f3f0e8   卡片淺米
--ink:       #1a1a1a   主深灰
--ink-2:     #5c5c5c   次中灰
--ink-3:     #9a9a9a   弱淺灰
--accent:    #7b5b48   焦糖棕（連結、強調）
--line:      #d4ccc0   細分隔線
--highlight: #e0d9cc   區塊高亮
```

### 字型系統
- **Display（標題、Z01 巨型字）**：Playfair Display 700/900 — 粗襯線字體，優雅而醒目
- **Serif Body（內文、報價）**：Lora 400 — 閱讀性佳的襯線字體
- **Sans Serif（meta、caption、按鈕）**：Open Sans 300/400 — 現代、清晰的無襯線字體
- **Monospace（編號、時間軸）**：IBM Plex Mono 400 — 簡潔的等寬字體

### 動態效果
1. **視差滾動**：Hero 圖片背景 `background-attachment: fixed` 模擬視差，營造深度。
2. **細微淡入**：區塊或圖片進入視口時，`opacity` 從 0 漸變至 1，`transform: translateY(10px)` 輕微上移，`transition: all 0.6s ease-out`。
3. **Hover 效果**：卡片或連結 `transform: translateY(-3px)` 輕微上浮，`box-shadow` 輕微擴散，`transition: all 0.2s ease-in-out`。
4. **流暢滾動**：`scroll-behavior: smooth`，提供更自然的頁面導航體驗。

### 構圖原則
- **12 欄網格系統**：內容嚴格遵循 12 欄網格，確保對齊與秩序感。
- **大面積留白**：強調內容間的呼吸空間，提升閱讀舒適度與高級感。
- **圖文混排**：圖片穿插在文字段落中，或作為全幅背景，文字疊加在圖片之上，營造雜誌版面感。
- **粗襯線標題**：標題使用 Playfair Display，字號大、字重高，與內文形成鮮明對比。
- **對稱與不對稱平衡**：善用文字塊、圖片與留白的非對稱佈局，創造視覺張力，但整體仍保持平衡。
- **頁碼與分隔線**：底部或側邊有簡潔的頁碼設計，章節之間用細線 `--line` 分隔，而非粗獷區塊。

## 頁面結構（8 區段）

```
1. Topbar           簡潔導航 + 展覽標題
2. Hero             全幅攝影圖 + 粗襯線大標 + 副標 + 導覽按鈕
3. § 策展論述       引言區 + 兩欄式內文 + 引文區塊
4. § 設計師名單     3 欄式卡片佈局，含設計師名、簡介、抽象圖
5. § Venue 場地     全幅場地氛圍圖 + 疊加文字區塊
6. § 五大展區       網格佈局，各展區卡片含編號、主題、簡短描述、代表圖
7. § 講座排程       簡潔表格，含日期、時間、講者、主題
8. § 票務           三欄式票種卡片，主打票種有輕微高亮
9. Footer           版權資訊 + 社交媒體連結 + 簡潔頁腳設計
```

## 文案 voice

以策展人視角，傳遞精緻、深思熟慮的觀點。語氣正式，帶有學術深度與設計評論的專業感。
- 使用優雅的長句與精煉的詞彙。
- 強調設計的「本質」、「脈絡」與「演進」。
- 避免口語化表達，注重邏輯與層次。
- 適度使用專業術語，但要確保解釋清晰。
- 引用或強調的文字會以斜體或不同的字重呈現。

## 互動行為

- Topbar 導航項目 hover 時，文字顏色變為 `--accent`。
- Hero 區塊的導覽按鈕 hover 時，背景色淺米 `--paper` 輕微加深，文字顏色變為 `--ink`。
- 區塊進入視口時，觸發細微淡入動畫。
- 設計師卡片 hover 時，輕微上浮並顯示柔和陰影。
- PURCHASE 按鈕現為 `disabled aria-label="Demo only — not for sale"`。
- 頁面滾動時，Hero 圖片背景視差滾動。

## a11y / 性能

- `<main>` landmark 包所有主內容。
- `prefers-reduced-motion: reduce` 停用所有視差、淡入、hover 動畫，僅保留基本視覺變化。
- Table `<th scope="col">` 標欄。
- 圖片全部 `loading="lazy" decoding="async" alt="描述性文字"`。
- 全 PNG 轉 WebP（~91% 大小縮減）。
- 確保文字與背景有足夠的對比度，符合 WCAG 2.1 AAA 標準。
- 導航與按鈕具備清晰的 `:focus` 狀態。
